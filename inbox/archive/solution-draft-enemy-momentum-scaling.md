# 方案草稿 — 敌人道念产出缩放曲线：矛盾收口

## 问题

`open-questions/01-combat.md:30` 登记了一条带矛盾的待答项：敌人各等级的道念**产出**能力随等级 / 境界 / 篇章如何缩放。

- `systems/enemies/_index.md`、`systems/enemies/common-properties.md`、`systems/adventure-event/combat/_index.md` 三处登记为「未定 → `systems/balance.md`」；
- `systems/balance.md` 的对应条目写的是「敌人侧的产出结构亦已定（无敌方专属缩放曲线，产出决定因素与玩家一致）」。

两种读法互斥。若 balance 侧成立 → 本条不存在，敌人产出随「等级 → 功法层数 → 卡组」间接缩放；若三处 enemies / combat 侧成立 → 还欠一条独立曲线。清单登记时未裁决，留待本次收口。

**收口结论（直读四份文档 + 溯源得出）：balance 侧成立，且它并非孤证——三份「未定」登记全部是各自文档 `## 待决问题` 小节里的过时残留，被它们自己文档 `## 意图` 小节的正文所推翻。**

### 结构性硬边界（说明「独立曲线」为何不可能被补回来）

即便抛开溯源，一条敌方专属产出缩放曲线也与三条已固化决策直接冲突：

- **`ADR-0090`（Accepted）**：层数逐条固定、赋级只动 `baseMomentum`；理由是「层数是严格升级、按定义就是第二条强度曲线」。一条产出乘区与层数浮动是同一件事的两种写法。
- **`ADR-0044`（`±2` 赋级带）**：`enemies/_index.md:36-37` —「否则 `±2` 带的数值安全性推导立刻失效」「不设护栏就等于在唯一可见的难度刻度（等级）之外再开一条不可见的强度轴」。
- **`systems/balance.md:497`**：「**接受「敌人侧不做规则层差异化」**：难度差异走 `baseMomentum` 与遭遇参数，不走规则分叉。规则层的不对称是第四条冗余旋钮，且是**玩家看不见的最不可读的一条**。」

## 建议方案

### 子项 1 — 裁定：balance 侧成立，本条不是待答项

`[既有推演]`

**建议按 balance 侧收口。** 依据是上文四条证据的合流：用户拍板（`archive/draft-0823b.md:29`）→ 答案日志归档（`log-0823b.md:11`）→ Accepted ADR（`ADR-0090:19`）→ 三份文档的 `## 意图` 正文（`enemies/_index.md:39` 等）全部一致；对立面只有三句无溯源的转发式残留，且转发目的地写着相反结论。

**收口后的完整表述（建议作为落笔口径）：**

> 敌人侧**不存在**独立的道念产出缩放曲线。敌人的产出能力由**卡组**决定，决定因素与玩家完全一致；不存在独立于卡牌数值的敌方隐藏乘区。等级只经 `baseMomentum` 表决定**起始道念**（起跑线），不作用于产出。

**因此 `open-questions/01-combat.md:30` 建议整条移除**（移出由 `/analyze-new-ideas` 执行，本技能不动清单）。它是一次**回归登记**——该问题已于 08-23 答结并归档，`log-0823b.md:11` 甚至预先写明了「不重复登记」。

`[通行做法]`
