# 设计方向 — 美术基调（视觉方向）

## 方向陈述

本作的视觉是**厚涂写实的中式卡牌插画，以水墨氛围点缀**——三国杀一路的绘画基底，不是弈仙牌式的风格化，更不是温馨明快的 Balatro。世界是**冷光暗调的 grimdark 修仙**：阴天漫射与冷月光作主光源，修行本身的灵光（法术、符箓、丹炉）是画面里唯一的暖色与异色——冷世界里唯一的光来自修行，与「攀登修仙阶梯求生」的核心幻想同构。人物**写实英气、不浪漫不卖萌也不刻意扮丑**；压抑感由色彩、光照与环境叙事承载，**不直给血腥**。全局一套低饱和暗色板打底，每个地域给背景板一个色相签名，主体靠焦点高对比在手机小屏上保持可读。

## 独有特色

- **「灵光是唯一的暖色」**：冷光暗调世界 + 修行灵光点缀的光照分工，把 grimdark 基调与修仙题材焊在同一条视觉规则上——它同时给了「主体焦点高对比」一个叙事理由，而不只是可读性妥协。
- **仙侠意象色的五类卡框，不套五行**：色彩语汇从各类卡牌自身意象取色，拒绝借五行色暗示不存在的相克关系——世界观表达与机制诚实兼得。
- **地域色相签名**：换地域即换色感，与「一地域一张事件背景板」的既有结构天然对齐，让三章 45–70 分钟的攀登在视觉上有推移感，而不动条目跨章复用的既定形态。

## 既有边界（interview 未重新讨论）

- 画风骨架：具绘画感的中式卡牌插画（三国杀 / 弈仙牌）× grimdark 仙侠、明确不温馨 → `vision/pillars.md`、`vision/references.md`、`art/_index.md`「继承的既有约束」。
- 卡面 full art、不预留文字区；插画内不烧入可翻译语义的文字（装饰性字符豁免）→ `art/visuals/art-direction.md`「构图」「文字与字符」。
- 缩略可辨 + 跨卡可区分（剪影 / 主色 / 构图）是硬约束 → `art/visuals/art-direction.md`、`ux/combat-ux.md`。
- 竖版、GL Compatibility、手机尺寸可读 → `art/_index.md` 约束表。
- 一条目一张、不随境界分版；境界感按条目叙事定位取沉 → `art/visuals/_index.md`、`handoffs/2026-08-30-realm-progression-artwork-basis.md`。
- 卡框色形态 = 外缘细描边 + 左边缘厚色带，具体色值受三条机械约束（缩略两两可辨 · 灰度化仍可辨 · 不与三套状态视觉相撞）→ `ux/combat-ux.md`。
- 生成工具 Midjourney（视觉）；guide 流水线三段结构；二进制资产归 `game-feature-branch/`、不经热更通道 → `art/_index.md`、`decisions/ADR-0125-no-binary-over-overlay.md`。

## 逐轴裁决

### 轴 1：绘画质感与笔触
**裁决：** 厚涂写实为主，水墨作氛围点缀（雾、尘、墨韵在氛围层，不是主体语言）。
**理由：** grimdark 的重量感需要暗部细节与材质感承载；Midjourney 对厚涂写实出图最稳；缩略尺寸下主体边缘清晰，利于「缩略可辨」硬约束。
**后果：** 每份 art guide 的 prompt 骨架以厚涂写实为基底词；水墨元素以氛围修饰词出现、不得反客为主。浓水墨 / 国画感被否决——偏离两个既定参照锚点、AI 稳定性与暗部表现更难控；风格化混合被否决——风格化的「轻」抵消 grimdark 阴郁。

### 轴 2：grimdark 的视觉表达尺度
**裁决：** 压抑由氛围承载（色彩、光照、残垣、枯骨远景、荒芜、人物神态），**不画血腥特写与恐怖直给**。
**理由：** 国内发行（版号 / 渠道审核对血腥暴力敏感）的现实边界会框定批量生成资产的返工风险；「留给想象」往往比直给更沉。
**后果：** 各 guide 的禁用词包含血腥特写、gore、断肢一类直给元素；日后若要上调尺度属发行期重估，不预留口子。

### 轴 3：色彩策略
**裁决：** 统一低饱和暗色板管全局 grimdark 底色 + 每个地域给事件背景板一个色相签名 + 主体焦点高对比（主体受光、环境沉暗）解决手机可读。全局色板**不随境界推移**。
**理由：** 与「一地域一张背景板」既有结构天然对齐，换地域即换色感；境界感已由「按条目叙事定位取沉」承担，色板绑章会与条目跨章复用（`EncounterScopes`）打架。
**后果：** art-direction.md「色彩」节按「暗基调公共板 + 地域签名色相 + 焦点对比」三层写；地域色相签名在 location 内容条目 / 背景板 guide 中逐地域登记。「色板随境界推移」与「完全统一一套」均否决。

### 轴 4：人物美型度
**裁决：** 写实英气（三国杀式）——人物写实、有英气与美感，但不锐化美型不卖萌；风霜、疲惫、伤痕按叙事定位入画。
**理由：** 在「仙侠受众的审美期待」与「grimdark 不浪漫」之间站中位，与厚涂参照系同源。
**后果：** 角色形象与敌人立绘的 guide 共用这条人物基调；「美型为底 + 残酷点缀」否决（脸上的「净」持续对冲 grimdark，易读成廉价仙侠）、「40k 式粗粝」否决（对仙侠受众第一眼吸引力最弱，起始角色是玩家投射对象尤其冒险）。

### 轴 5：光照性格
**裁决：** 冷光主调 + 灵光点缀——阴天漫射 / 冷月光作主光源，法术、符箓、丹炉等修行「灵光」作局部暖 / 异色点缀。
**理由：** 「冷世界里唯一的光来自修行」与核心幻想同构，同时给焦点高对比一个叙事理由。
**后果：** art-direction.md「光照与材质」节以此为基调；灵光的色相家族与五类卡框的意象色（轴 6）在 guide 期需协同取值，避免与三套状态视觉相撞。烛火暖光主调否决（易滑向温馨）、戏剧性硬光否决（大面积暗部在缩略下吃掉主体细节）。

### 轴 6：五类卡框色的色彩语汇
**裁决：** 仙侠意象色，不套五行——每类从自身意象取色（如业障取瘴紫黑、阵法取符箓金一类方向），色相选择以三条机械约束为优先，意象服从可辨性。
**理由：** 五类卡牌与五行并无语义对应，硬套会误导玩家寻找不存在的相克关系，且未来若引入灵根 / 属性系统再用五行色会撞车；白与黄在暗基调小屏上可辨性吃紧。
**后果：** 具体色值仍归美术定稿（`open-questions/01-combat.md` 09-08 那条待答项的取值格照旧），但其语汇前提自此锁定；纯功能色（色轮等距）否决——浪费一层免费的世界观表达。

### 轴 7：UI 元件的材质隐喻
**裁决：** 暗色扁平打底 + 古物细节点缀（简牍纹、印泰、符纹描边落在边角），仙侠味由点缀与插画承担。
**理由：** 可读性与九宫格拉伸最友好、GL Compatibility 零压力；信息密度最高的战斗屏不被材质噪声干扰。
**后果：** UI 类目 guide 以扁平暗色为基、点缀素材单列；拟物古物材质否决（小屏高密度下易脏、拉伸穿帮、状态变体费力）、水墨笔触 UI 否决（墨边不规则轮廓与拉伸 / 最小触控尺寸相抖，灰态降饱和在墨色上读不出）。

### 轴 8：UI 元件的制作路径（关闭 `visuals/_index.md` 待决项）
**裁决：** 混合路径——扁平底子（面板 / 按钮底 / 状态变体）由人工 / 矢量制作，不进 AI 流水线；古物点缀素材（符纹、印泰、纹样）走 Midjourney 生成后裁切入 UI。
**理由：** 扁平底子本就是纯色块与描边，AI 无增益；点缀素材恰是 AI 低成本产出的甜区；与轴 7 的材质分工一一对应，九宫格与状态变体零风险。
**后果：** `visuals/_index.md`「UI 元件是否走 AI 生成」待决项关闭；UI 类目的 guide 只覆盖点缀素材一半，底子那一半不建 guide。

### 轴 9：guide 的粒度（关闭 `visuals/_index.md` 待决项）
**裁决：** 类目 guide + 条目变量——一个资产类目一份 guide，逐条目只填主体 / 构图 / 情绪变量；少数需要特殊表达的条目（Finale 敌人、关键角色）可例外升格为独立 guide。
**理由：** 分次生成的最大风险是风格漂移，稳定性优先；表达力缺口由显式的例外升格通道兜住。
**后果：** `guides/_TEMPLATE.md` 按「类目公共段 + 条目变量段」组织；例外升格须在类目 guide 中登记指针，避免两份 guide 各自漂移。

## 张力

无——九轴裁决均在既有决策与 ADR 框定的选项空间内，无一推翻既有权威。

## 留白（用户明确不在本次定的）

- **AI 生成资产的商用授权与参考素材来源的合规口径**：属法律 / 发行问题而非视觉取向，明确排除在本场范围外，照旧挂在 `art/_index.md` 待决问题（它仍是选工具的前置，本场裁决不改变其地位）。

## 配套默认（可推演项，非 interview 裁决）

- **五色具体色值与两枚战报符号字形**：按既定三条机械约束（缩略两两可辨 · 灰度化仍可辨 · 不与三套状态视觉相撞；符号非数字 · 单字宽 · 互不相似）在 guide 编写期定稿——本场只锁语汇（轴 6），不代取值。→ `open-questions/01-combat.md`
- **尺寸格式与图集策略**（art-direction.md「技术约束」待写格）：留待首批 guide 按 Midjourney 输出规格与 Godot 导入实测定，方向层不锁数值——标准工程实践，无取向成分。
- **参考素材二进制**：沿既有暂定「只登记来源与描述、实际文件暂放本地」，本场不动。→ `art/visuals/references/_index.md`
- **一句话方向陈述**（用户授权按本场裁决起草）：「厚涂写实的中式卡牌插画、水墨氛围点缀；冷光暗调的 grimdark 修仙世界，修行的灵光是唯一的暖色；人物写实英气、不浪漫不卖萌；压抑靠氛围而非血腥；竖版构图、暗底之上主体高对比。」——措辞可在提炼时打磨，语义以逐轴裁决为准。
