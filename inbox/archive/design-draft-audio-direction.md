# 设计方向 — 音频与听觉基调

## 方向陈述

本作的听觉是**东方史诗配器骨架上的 grimdark 修仙**——以《三国杀》主题 BGM 的范式为骨（自然小调的苍凉、五声化旋律动机、民族前景 + 管弦中景 + 电子氛围后景 + 战鼓低频的四层配器），在其上叠一层本作专属的**诡暗之色**（不协和音簇、诡异音色处理、更多留白与不安），把三国杀的「苍凉肃穆」升级为本作的「阴郁不祥」。**纯器乐、无人声无配音**（与 Balatro 同路），**为耳机聆听混音**。常规战斗的音乐站在**低位压迫**档，把全配器爆发只留给 Finale；三个篇章越往高境界走，世界听起来**越空旷孤高**——登得越高，越孤独越凶险。它与 Balatro 的差别在温度（阴郁 vs 明快），与三国杀的差别在色彩（诡暗 vs 肃穆），与 Darkest Dungeon 的差别在身份（东方民乐音色始终是前景）。

## 独有特色

- **「史诗为骨、诡暗为色」**：整体沿用经过验证的东方史诗范式保住身份与稳定性，本作的辨识度由叠加其上的阴暗层承载——与视觉侧「借三国杀画风、不借其温度」是同一条策略在听觉上的镜像。
- **「爆发只留给 Finale」**：常规战斗低位压迫、鼓点克制，能量落差本身成为 Finale「大战感」的来源——与深思熟虑的回合制手感对齐，音乐不催促玩家。
- **「越登越空」**：篇章氛围随境界推进走织体稀薄化、混响加深、音区极端化（极高泛音 + 极低 drone），与「攀登修仙阶梯、在弱肉强食世界中求生」的核心幻想同构：高处不胜寒。

## 既有边界（interview 未重新讨论）

- 基调：东方仙侠 × grimdark，阴郁、高风险、不浪漫；明确不温馨（对 Balatro 的规避）、不用西式高奇幻管弦语汇 → `vision/pillars.md`、`art/soundtracks/audio-direction.md`「基调」。
- 视觉与听觉同一基调、不得各说各话 → `art/soundtracks/audio-direction.md`。
- BGM 须无缝循环（对局时长不定）→ `art/soundtracks/_index.md`、`audio-direction.md`「技术约束」。
- **静音容错纪律保留**：音频是增益、不是唯一信息通道，一切听觉信息须有视觉等价物（本场只改混音基准场景，不动这条纪律）→ `art/soundtracks/_index.md`「移动端约束」。
- 六个资产类目清单（主题曲 / 战斗 BGM / 事件探索 BGM / 篇章氛围 / UI 音效 / 反馈音效）→ `art/soundtracks/_index.md`。
- 三条音量轨的字段与持久化形态 → `systems/player-profile/game-setting.md`。
- 生成流水线三段结构；二进制资产归 `game-feature-branch/`、不经热更通道 → `art/_index.md`、`decisions/ADR-0125-no-binary-over-overlay.md`。

## 参照锚（本场新登记）

- **《三国杀》主题 BGM**（分析文档：仓库根目录 `三国杀主题BGM音乐分析.md`，提炼时应将其结论登记进 `art/soundtracks/references/_index.md`）。**借**：自然小调（爱奥利亚）的苍凉底色、五声化旋律动机与围绕主音的回旋、四层配器分工（民族前景 / 管弦中景 / 电子氛围后景 / 低频蓄势）、恒定节拍上靠织体密度而非提速的推进方式、「蓄势—爆发—抽离」浪潮结构与断裂留白、以时长而非峰值维持高潮、余韵式极弱尾声。**不借**：其「战争史诗」的肃穆大气取向（本作要在其上加诡暗层）、其主菜单曲的单曲定位（本作按六类目分别编写 guide）。
- **Balatro**：借「背景纯音乐、无人声」的定位；不借其温馨明快。

## 逐轴裁决

### 轴 1：三国杀范式的取舍
**裁决：** 史诗为骨 + 诡暗为色——整体沿用四层配器与自然小调苍凉路线，在其上叠本作专属的阴暗层（不协和音簇、诡异音色处理、更多留白与不安）。
**理由：** 参照锚经过验证、生成稳定性高；但「苍凉肃穆」与 grimdark 的「阴郁不安」有差距，视觉侧已定的压抑基调要求视听不得各说各话——与视觉「借画风不借温度」同构。
**后果：** `audio-direction.md` 的配器节按四层分工写，另立「诡暗层」为本作专属追加段；「整体照搬」与「只借结构、配器重定」均否决（前者视听基调脱节，后者丢掉参照锚大部分价值）。

### 轴 2：人声
**裁决：** 纯音乐——无人声、无配音，暂不考虑任何人声形态（用户开场直接拍板，Balatro 同路）。
**理由：** 用户明确表态；无歌词即无本地化负担，生成也最稳。
**后果：** 全部六类目均为纯器乐；禁用清单纳入有词歌与旁白。日后若重估人声属新一轮方向裁决，不预留口子。

### 轴 3：混音基准场景
**裁决：** 为**耳机聆听**混音——音效与 BGM 的打磨不考虑手机外放场景（用户开场直接拍板）。
**理由：** 用户明确表态以耳机体验为准。
**后果：** 低频层（四层配器的蓄势层）在耳机下完全可用，反而强化范式的低频设计；`audio-direction.md`「动态与混音」节以耳机为基准写响度与频段分工。**本裁决推翻既有陈述,见「张力」。**

### 轴 4：音频投入的角色定位
**裁决：** BGM 氛围优先——主题曲与篇章氛围先立起来，grimdark 听觉基调由 BGM 承载；音效类目后补。（用户在推荐「反馈音效优先」与本项之间明确选择了本项。）
**理由：** 氛围身份先立，一次定调。
**后果：** guide 编写顺序为 BGM 类目（主题曲最先）→ 音效类目；音效方向仍在本场锁定（轴 7）以免日后漂移，但打磨深度与预算后置。

### 轴 5：战斗 BGM 的能量性格
**裁决：** 常规战斗低位压迫、鼓点克制（低频脉冲 + 稀疏战鼓 + 民族音色短动机，压迫常驻但不轰炸）；全配器高潮只留给 Finale。
**理由：** 深思熟虑的回合制手感要求音乐不催促玩家；循环几十分钟不累；能量落差本身成为 Finale 强度区分的来源，满足既有「Finale 应有区别于常规战斗的强度」。
**后果：** 战斗 BGM guide 与 Finale guide 分开编写、共享动机但配器密度分档；「全程高能」与「随回合动态升压」均否决（前者与手感相抵且 Finale 失去落差，后者需分层音轨工程、Suno 类工具产成品曲不产分层素材，首版风险高）。

### 轴 6：篇章推进的音乐语言
**裁决：** 越走越空旷孤高——章一织体较满、人间烟火尚存；越往高境界织体越稀薄、混响越深、音区越极端（极高泛音 + 极低 drone）。
**理由：** 与「攀登修仙阶梯、弱肉强食中求生」的核心幻想同构：登得越高越孤独越凶险；与视觉「境界感按条目叙事定位取沉」不冲突（听觉承担进程感是既有约定）。
**后果：** 三份篇章氛围 guide 按「织体密度 / 混响深度 / 音区分布」三个参数拉开梯度；「越走越宏大厚重」否决（听感偏胜利凯歌，与 grimdark 沉重结局相拧）、「越走越阴暗扭曲」否决（诡暗从点缀升为主体，三章失去推移层次对比）。

### 轴 7：音效的材质性格
**裁决：** 古物实材质——出牌、结算、按钮、翻页用仙侠世界的实物声做词汇：纸张 / 竹简翻动、玉磬与铜铃、剑鸣与布帛、木鱼与石磬一类。
**理由：** 与视觉 UI「暗色扁平打底 + 古物细节点缀」对称，仙侠味由材质承载,听觉与视觉的世界感不割裂。
**后果：** 音效 guide 以实材质采样感为基底词；已知风险登记在案——高频重复听的打击感需打磨（实材质声容易软），出牌音在 guide 期须做「几十次重复可听」专项校验。「中性打击感优先」与「音乐性音效」否决（前者世界感割裂，后者首版工程投入高）。

### 轴 8：寿元告警的听觉 / 触觉反馈（关闭挂账待答项）
**裁决：** 跌破低位阈值那一刻播**一次性低调提示音**（短促低沉，如一声闷钟）；不循环、不常驻、不震动。
**理由：** 寿元是唯一命线，被削到低位是全局最重的状态变化，值得一次听觉确认；一次性不骚扰，与 grimdark 的克制一致。
**后果：** `ux/screen-flow.md` 与 `art/soundtracks/_index.md` 的「寿元告警是否伴音 / 震动」待决项可关闭；视觉「静态标注」形态不变，提示音是叠加而非替代;完全静默与「音 + 震动」均否决。

### 轴 9：生成工具定案
**裁决：** 本场**不拍板**——维持「倾向 Suno、guide 暂按 Suno 形态组织、工具专属语法不写死进模板」的既定约定，正式定案等商用条款合规核查。
**理由：** 商用条款是选型的一部分而合规口径尚未核查；与视觉场对 Midjourney 的留白对称处理。
**后果：** `soundtracks/_index.md` 的工具待决项保持在案，不因本场关闭。

## 张力

- **轴 3（耳机优先）推翻 `audio-direction.md`「动态与混音」节的既有陈述**：「**手机外放**是主要收听场景，低频基本听不见——重要信息不能只挂在低频上」。用户明确有意推翻——混音基准改为耳机,提炼时应改写该句。代价：外放玩家的听感不再被保证（低频层在外放下会缺失），接受此代价；**「静音容错」纪律不在推翻之列**（听觉信息须有视觉等价物照旧），因此外放缺失不构成信息缺失。

## 留白（用户明确不在本次定的）

- **生成工具的正式拍板与 AI 生成音频的商用授权合规口径**：轴 9 明确维持现状，合规核查是拍板前置——与视觉场对 Midjourney 的留白同一条，照旧挂在 `art/_index.md` 与 `soundtracks/_index.md` 待决项。
- **BGM 时长与码率的包体预算**：既有待决项，非取向问题，本场不动。→ `open-questions/deferred-content.md`。

## 配套默认（可推演项，非 interview 裁决）

- **一句话方向陈述**（用户授权按本场裁决起草，供 `audio-direction.md` 开头、可直接放进 prompt）：「东方史诗骨架上的 grimdark 修仙配乐:民族乐器前景、管弦中景、电子氛围后景、低频蓄势的四层配器;自然小调的苍凉之上叠不协和与诡异音色的诡暗之色;纯器乐无人声;恒定节拍、以织体密度而非速度推进;压迫常驻而爆发克制,留白与不安是常态。」——措辞可在提炼时打磨，语义以逐轴裁决为准。
- **禁用清单初稿**（由裁决与既有边界推演）：祥和国风轻音乐 / 古筝轻音乐、节庆喜庆锣鼓、温馨明快（Balatro 向）、西式高奇幻管弦语汇（圣咏 / 凯尔特 / 铜管凯旋）、有词歌与旁白 / 配音、电子舞曲律动。供 `audio-direction.md`「禁用清单」节按 🔵 采纳。
- **调式与节奏节的骨架**（由轴 1 推演）：自然小调（爱奥利亚）中心、五声化旋律动机、恒定节拍 4/4 网格、以织体密度而非提速做推进、「蓄势—爆发—抽离」浪潮结构与断裂留白作为主题曲 / Finale 的作曲逻辑参考——均直接继承参照锚分析结论。
- **响度目标与频段分工的具体数值**：归 guide 编写期与真机实测（耳机基准），方向层不锁数值；三条音量轨默认值的实测校准照旧待定。
- **战斗 BGM 循环长度、各类目条数**：随包体预算与 guide 实测定，方向层不锁。
