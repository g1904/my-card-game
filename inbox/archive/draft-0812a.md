Let's talk about deck building this session.
- As said before, the starting deck is like hearthstone arena mode, where player choose among options several times to build a deck.
- now let's introduce a new concept called '功法' / cultivationTechnique, basically it consists of one or more cards that must be played in a deck together.
- a deck is consists of one or more cultivationTechnique.
- each type of cultivationTechnique is like a unique type of Pokémon that can envolve as the game progress.
- cultivationTechnique has a level field indicates how advance the character has studied the technique.
- when game start, a random character is assigned.
- each character comes with a characterPower and two cultivation techniques (that ties to the character, each run with this character will have the same power and cultivation techniques). 
- among the starting events, there will always be one that let the player choose among three cultivation techniques to add to their deck as well as one among three characterItem.
- a deck can have any number of cards depending on how many cultivation techniques they run and how many cards in each cultivation techniques.
- player will get to upgrade the level of the cultivation techniques or discard one that already chosen or learn new ones through out the adventureEvent.
