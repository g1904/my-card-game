# 总视觉方向（Art Direction）

**所有 art guide 的公共约束。** 每份 guide 都继承本文档，并只在其上追加该资产特有的部分。跨资产的风格一致性由本文档承担——资产由 Midjourney 分次生成，没有共同上游必然漂移。## 一句话方向

> **厚涂写实的中式卡牌插画、水墨氛围点缀；冷光暗调的 grimdark 修仙世界，修行的灵光是唯一的暖色；人物写实英气、不浪漫不卖萌；压抑靠氛围而非血腥；竖版构图、暗底之上主体高对比。**

骨架：**具绘画感的中式卡牌游戏插画（三国杀 / 弈仙牌 一路）× grimdark 仙侠基调**——即「好看的中式插画」不等于「祥和的仙侠」，本作是阴郁、高风险、不浪漫的。

### 绘画质感与笔触

- **厚涂写实为主。** 每份 art guide 的 prompt 骨架以厚涂写实为基底词：grimdark 的重量感靠暗部细节与材质感承载，且厚涂主体在缩略尺寸下边缘清晰，直接服务于「缩略可辨」硬约束。
- **水墨作氛围点缀，不作主体语言。** 雾、尘、墨韵一类元素以**氛围修饰词**出现，落在氛围层；**不得反客为主**。浓水墨 / 国画感的主体表达不在本作范围内——它偏离两个参照锚点，且暗部表现与生成稳定性都更难控。
- **不做风格化混合。** 风格化天然带来的「轻」会对冲 grimdark 的阴郁。

## 基调

- **grimdark。** 阴郁、高风险、后果沉重。取 Warhammer 40k 的**精神**，不取其设定（我们是仙侠，不是科幻）。
- **明确不要：** 温馨、明快、低风险的观感（对 Balatro 的规避，见 `../../vision/references.md`）。
- **修仙是残酷的攀登**，不是逍遥游。境界越高，画面应越沉 —— **按条目自身的叙事定位取沉，不按运行时赋级取沉**：一条被 `ChapterScope` 框在第三篇章的敌人天生更沉，而同一条目在运行时被赋到哪一档境界不改变它的画面。**故没有任何类目需要为境界出多套资产**（唯一例外是角色形象的稀疏境界覆写，见 `_index.md` 类目表）。

### 残酷的表达尺度（承重）

- **压抑由氛围承载，不由血腥承载。** 可用的语汇是：色彩与光照、残垣断壁、远景枯骨、荒芜的环境叙事、人物的神态与风霜。
- **不画血腥特写与恐怖直给。** gore、断肢、内脏、伤口特写一类元素进入**每份 guide 的禁用词**。两个理由：「留给想象」往往比直给更沉；而批量生成的资产一旦踩线，返工成本按资产数放大。
- **这条尺度不预留上调口子。** 若日后确要上调，属发行期的整体重估，而不是逐份 guide 的自由裁量。

## 色彩

色彩策略分**三层**，自下而上叠加：

1. **暗基调公共板（全局）。** 一套低饱和、低明度的公共色板打底，管住全库 grimdark 的底色。它**不随境界推移**——境界感已由「按条目自身叙事定位取沉」承担（见「基调」），色板若绑篇章，会与条目跨章复用（`EncounterScopes`）的既定形态打架：同一条目在两章里要有两套画。
2. **地域色相签名（分区）。** 每个地域给它的事件背景板一个**色相签名**，换地域即换色感。这与「一地域一张事件背景板」的既有结构天然对齐（见 `_index.md` 类目表），让一次攀登在视觉上有推移感。逐地域的具体色相登记在各 location 内容条目与对应的背景板 guide 中，不在本文档铺开。
3. **主体焦点高对比（逐资产）。** 主体受光、环境沉暗——低饱和暗基调与「手机小屏上清晰可读」的调和点在**局部对比**，而不是整体提亮。这一层同时被「光照与材质」的灵光点缀在叙事上兜住，故它不是可读性的妥协，而是世界规则的一部分。

**五类卡框色的色彩语汇：仙侠意象色，不套五行。** 每类从自身意象取色（业障取瘴紫黑、阵法取符箓金一类方向）。**不借五行色**——五类卡牌与五行并无语义对应，硬套会诱导玩家去找一套并不存在的相克关系；且日后若引入灵根 / 属性系统，五行色会当场撞车。**意象服从可辨性**：色相的最终选择以 `../../ux/combat-ux.md` 的三条机械约束为优先（缩略尺寸下两两可辨 · 灰度化后仍两两可辨 · 不与三套状态视觉相撞），意象只在满足约束的候选中挑。白与黄在暗基调的小屏上可辨性吃紧，取色时留意。**具体色值归 guide 编写期定稿**，本文档只锁语汇。

## 光照与材质

**冷光主调 + 灵光点缀。**

- **主光源是冷的：** 阴天漫射、冷月光、雪光、水面反光。方向以侧上方与背侧为主，避免正面平光。
- **唯一的暖色与异色来自修行：** 法术、符箓、丹炉、灵器的「灵光」作**局部**暖 / 异色点缀。「冷世界里唯一的光来自修行」与「攀登修仙阶梯求生」的核心幻想同构，并给上一节的焦点高对比一个叙事理由。
- **灵光的色相家族须与五类卡框的意象色协同取值**——两者会同处一张画面 / 一块屏幕，且都要避开合法目标的呼吸描边、来源条目的上浮描边、灰态降饱和这三套状态视觉。
- **不用烛火暖光作主调**（易滑向温馨，与基调相反），**不用戏剧性硬光**（大面积暗部在缩略尺寸下会吃掉主体细节，直接损伤「缩略可辨」）。
- **氛围元素**（雾、尘、烟、墨韵）落在氛围层，用来拉开空间层次与压低远景，不用来遮盖主体。

## 人物

**写实英气。** 人物写实、有英气与美感，但**不锐化美型、不卖萌，也不刻意扮丑**。风霜、疲惫、伤痕按该条目自身的叙事定位入画。

这条基调由**角色形象与敌人立绘两个类目共用**。两端都不取：「美型为底 + 残酷点缀」会让脸上的「净」持续对冲 grimdark，读起来像廉价仙侠；40k 式的粗粝对仙侠受众的第一眼吸引力最弱，而起始角色是玩家的投射对象，在那里冒险代价最高。

## UI 元件的材质隐喻

**暗色扁平打底 + 古物细节点缀。** 面板、按钮、容器以暗色扁平色块与描边为基；简牍纹、印泥、符纹描边一类古物细节落在**边角**作点缀。仙侠味主要由插画与点缀承担，不由 UI 底材承担。

理由是三条同时成立：可读性与九宫格拉伸最友好、GL Compatibility 下零压力、信息密度最高的战斗屏不被材质噪声干扰。**不做拟物古物材质**（小屏高密度下易脏、拉伸穿帮、状态变体费力）；**不做水墨笔触 UI**（墨边的不规则轮廓与拉伸和最小触控尺寸相抵，且灰态的降饱和在墨色上读不出来）。

制作路径（哪一半走 AI、哪一半不走）见 `_index.md` 的「承重约定」。

## 构图

- **竖版**为基准（卡面与全屏插图皆然）。
- **卡面不预留文字区（full art）：** 插画铺满整个卡面，**不为文字留白**——卡面只由 UI 叠加层显示 `manaCost`，卡名与规则文字一律在详情页（见 `../../ux/combat-ux.md`）。卡框色与类型角标属「UI 元件与框架」类目、与插画分开生成（见 `_index.md` 类目表），不占插画的构图预算。
- **缩略可辨（跨卡可区分）：** 手牌区的卡面很小**且不显示卡名**，插画是玩家在手牌区辨牌的**唯一通道**。故不仅主体要在缩略尺寸下能辨认，同类目各卡的主体还必须在**剪影 / 主色 / 构图**上彼此有别——只做到「看得出画的是什么」不够，要做到「在一手牌里认得出是哪一张」。这是硬约束，不是偏好。
- 背景类资产**不得与前景 UI 抢读**。

## 文字与字符

**插画内不得烧入承载可翻译语义的文字。** 卡名、规则文字、UI 文案、可读为语句的招牌与题字，一律不入图。适用于**全部七个资产类目**——敌人立绘、事件插图、屏幕背景同样受此约束。

理由：承载语义的文字烧进美术资产，等于把语言数焊进资产本身——切语言时它静默留在中文，且失去热更通道；而 UI 文案一律走 `res://text/` 翻译键（`.claude/rules/ui-input-rules.md`），插画里的字面量绕过这个唯一的语言开关。

**豁免：** 不可读为语句的**装饰性字符形态**允许出现——符箓上的符文纹样、书法笔触、印章、匾额、残缺碑文皆可。条件是它**不传达任何玩家需要读懂的信息**。本作有「叠嶂符」这类以符箓为主体的牌，画一张符而符上无纹样是自相矛盾的；受约束的是可翻译的语义，不是笔画本身。

## 禁用清单

每份 guide 的禁用词至少包含下列各项。

**题材与外衣**

- **西式高奇幻的外衣**（`../../vision/pillars.md` 反目标）。
- **特定 IP 的可识别元素**——Warhammer 40k 只借基调，不借其科幻设定与任何具体符号（见 `references/_index.md`）。
- **过度光鲜的仙侠俗套**：明媚天光下的飘带御剑、糖水质感的宫廷仙子、无风霜的完美面孔。

**残酷尺度**

- **血腥直给**：gore、断肢、内脏、伤口特写、血泊。压抑走氛围，见「基调」的残酷尺度一节。

**风格**

- **浓水墨 / 国画感的主体表达**（水墨只作氛围修饰词）。
- **明快、温馨、低风险的观感**——对 Balatro 的规避，见 `../../vision/references.md`。
- **卡通化 / 萌系比例与表情**。

**技术与可读性**

- **烧入插画的可翻译文字**（装饰性字符豁免，判据见「文字与字符」）。
- **大面积硬光造成的重暗部**——缩略尺寸下会吃掉主体细节。
- **背景元素抢读前景 UI 的高对比 / 高饱和块面**。
