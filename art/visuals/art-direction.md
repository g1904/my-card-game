# 总视觉方向（Art Direction）

**所有 art guide 的公共约束。** 每份 guide 都继承本文档，并只在其上追加该资产特有的部分。跨资产的风格一致性由本文档承担——资产由 Midjourney 分次生成，没有共同上游必然漂移。## 一句话方向

> _（待写：一句能直接放进 prompt 开头的风格陈述。）_

已知的骨架：**具绘画感的中式卡牌游戏插画（三国杀 / 弈仙牌 一路）× grimdark 仙侠基调**——即「好看的中式插画」不等于「祥和的仙侠」，本作是阴郁、高风险、不浪漫的。

## 基调

- **grimdark。** 阴郁、高风险、后果沉重。取 Warhammer 40k 的**精神**，不取其设定（我们是仙侠，不是科幻）。
- **明确不要：** 温馨、明快、低风险的观感（对 Balatro 的规避，见 `../../vision/references.md`）。
- **修仙是残酷的攀登**，不是逍遥游。境界越高，画面应越沉 —— **按条目自身的叙事定位取沉，不按运行时赋级取沉**：一条被 `ChapterScope` 框在第三篇章的敌人天生更沉，而同一条目在运行时被赋到哪一档境界不改变它的画面。**故没有任何类目需要为境界出多套资产**（唯一例外是角色形象的稀疏境界覆写，见 `_index.md` 类目表）。

## 构图

- **竖版**为基准（卡面与全屏插图皆然）。
- **卡面不预留文字区（full art）：** 插画铺满整个卡面，**不为文字留白**——卡面只由 UI 叠加层显示 `manaCost`，卡名与规则文字一律在详情页（见 `../../ux/combat-ux.md`）。卡框色与类型角标属「UI 元件与框架」类目、与插画分开生成（见 `_index.md` 类目表），不占插画的构图预算。
- **缩略可辨（跨卡可区分）：** 手牌区的卡面很小**且不显示卡名**，插画是玩家在手牌区辨牌的**唯一通道**。故不仅主体要在缩略尺寸下能辨认，同类目各卡的主体还必须在**剪影 / 主色 / 构图**上彼此有别——只做到「看得出画的是什么」不够，要做到「在一手牌里认得出是哪一张」。这是硬约束，不是偏好。
- 背景类资产**不得与前景 UI 抢读**。

## 文字与字符

**插画内不得烧入承载可翻译语义的文字。** 卡名、规则文字、UI 文案、可读为语句的招牌与题字，一律不入图。适用于**全部七个资产类目**——敌人立绘、事件插图、屏幕背景同样受此约束。

理由：承载语义的文字烧进美术资产，等于把语言数焊进资产本身——切语言时它静默留在中文，且失去热更通道；而 UI 文案一律走 `res://text/` 翻译键（`.claude/rules/ui-input-rules.md`），插画里的字面量绕过这个唯一的语言开关。

**豁免：** 不可读为语句的**装饰性字符形态**允许出现——符箓上的符文纹样、书法笔触、印章、匾额、残缺碑文皆可。条件是它**不传达任何玩家需要读懂的信息**。本作有「叠嶂符」这类以符箓为主体的牌，画一张符而符上无纹样是自相矛盾的；受约束的是可翻译的语义，不是笔画本身。
