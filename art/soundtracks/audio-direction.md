# 总音频方向（Audio Direction）

**所有 audio guide 的公共约束。** 每份 guide 继承本文档，只在其上追加该曲目 / 音效特有的部分。跨曲目的听感一致性由本文档承担。

Source: `handoffs/2026-09-09c-audio-direction-nine-axes.md`

## 一句话方向

> **东方史诗骨架上的 grimdark 修仙配乐：民族乐器前景、管弦中景、电子氛围后景、低频蓄势的四层配器；自然小调的苍凉之上叠不协和与诡异音色的诡暗之色；纯器乐无人声；恒定节拍、以织体密度而非速度推进；压迫常驻而爆发克制，留白与不安是常态。**

这一段可直接放进 prompt 开头。措辞可随实测打磨，语义以下文各节为准。

## 基调

- 与 `../visuals/art-direction.md` **同一基调**：阴郁、高风险、不浪漫。视觉与听觉不得各说各话。
- **史诗为骨、诡暗为色。** 骨架取「东方史诗」范式（见 `references/_index.md` 的参照锚），本作的辨识度由叠加其上的**阴暗层**承载：不协和音簇、诡异音色处理、更多留白与不安。参照锚的「苍凉肃穆」在本作要被推到**阴郁不祥**。
- **明确不要：** 温馨明快；西式高奇幻的管弦语汇（对应 `../../vision/pillars.md` 反目标）；祥和国风轻音乐。
- 与各参照系的差别可作为 prompt 的校准句：与 Balatro 的差别在**温度**（阴郁 vs 明快），与东方史诗范式的差别在**色彩**（诡暗 vs 肃穆），与 Darkest Dungeon 的差别在**身份**（东方民乐音色始终在前景）。

## 配器与音色

**四层配器分工**（六个类目共用同一套声场纵深）：

| 层 | 内容 | 职责 |
|---|---|---|
| 前景 | 民族乐器旋律音色（拨弦类的明显起音瞬态、吹管 / 拉弦类的长延音） | 文化身份；旋律动机的主要载体 |
| 中景 | 弦乐群与管弦织体主体 | 厚度与重量 |
| 后景 | 合成器 Pad、持续环境音、深混响 | 空间纵深——「近处的人物 / 远处的战场」 |
| 低频 | 低音弦乐、合成低音、大型打击与持续低频脉冲 | **蓄势**：先以重量压住，再让上方织体爆发 |

**诡暗层（本作专属追加）：** 在上述四层之上叠不协和音簇、被处理过的诡异音色（失谐、反转、颗粒化的民族音色）、以及比参照锚更多的留白与不安。它是**着色层**，不喧宾夺主——一旦升为主体，三个篇章之间的推移层次就没有对比空间了。

**人声：纯器乐，无人声、无配音。** 六个类目一律不含有词歌与旁白。它同时是「无本地化负担」与「生成最稳」的选择，并与内容层「敌人台词是文本、不是音频资产」的既定形态一致。

## 调式与节奏

- **自然小调（爱奥利亚）中心**：没有导音上行的推力，听感古朴、开阔——这正是「苍凉」而非「戏剧化悲情」的来源。
- **五声化旋律动机**，围绕主音上下回旋；乐句多以下行收束。写作方式是**主题动机型**：一个辨识度高的核心动机在不同段落反复出现，每次由不同音色与更厚织体重新着色。这也是循环 BGM 长时间耐听的关键。
- **和声开放、功能弱化**：持续低音 / 低音踏板、空五度与四五度叠置、块状平行推进。戏剧推动力来自音区、力度、织体密度与配器增量，而非和弦进行。
- **恒定节拍、4/4 网格**。**推进方式是加密织体，不是提速**：起音密度逐层叠加，产生「压力越来越大」而非「越来越快」的心理感受。
- **主题曲与 Finale 的作曲逻辑参考「蓄势—爆发—抽离」的浪潮结构**：每次爆发都以低频重量蓄势、以配器叠层爆发、以突然的织体抽离留白；高潮**以时长而非峰值**维持，尾声以极弱收束。

## 动态与混音

- **混音基准场景 = 耳机聆听。** 响度目标与频段分工均以耳机为准；低频蓄势层在耳机下完全可用，四层配器的低频设计因此得到强化。**外放场景不作打磨对象**——外放玩家会缺失低频层，这个听感代价是被接受的取向。
- **它不放松静音容错。** 一切听觉信息仍须有视觉等价物（见下方技术约束），因此低频层在外放下缺失**不构成信息缺失**。
- **动态范围留宽**：常规战斗与 Finale 之间的能量落差是本作的主要戏剧手段，压缩过狠会把它抹平。
- **BGM 与音效的频段分工**：音效落在中高频的瞬态窗口，BGM 的低频蓄势层与之不争位；出牌 / 结算一类高频重复的音效不得占用与 BGM 动机相同的频段。
- **具体数值**（响度目标、各层频段边界）留待 guide 编写期与真机实测（耳机基准）定，方向层不锁数值。

## 场景与篇章性格

**战斗的能量档：**

- **常规战斗低位压迫、鼓点克制**——低频脉冲 + 稀疏战鼓 + 民族音色短动机，压迫常驻但不轰炸。深思熟虑的回合制要求音乐不催促玩家，且要经得起循环几十分钟。
- **全配器高潮只留给 Finale。** 战斗 BGM 与 Finale 各写一份 guide，**共享动机、配器密度分档**；能量落差本身就是 Finale「大战感」的来源。

**篇章推进：越走越空旷孤高。** 三份篇章氛围 guide 按三个参数拉开梯度——

| 篇章 | 织体密度 | 混响深度 | 音区分布 |
|---|---|---|---|
| 炼气 → 筑基 | 较满，人间烟火尚存 | 中等 | 中音区为主 |
| 筑基 → 金丹 | 变薄 | 加深 | 两端开始拉开 |
| 金丹 → 元婴 | 稀薄 | 最深 | 极端化：极高泛音 + 极低 drone |

登得越高越孤独越凶险——听觉承担进程感，与核心幻想同构。

## 音效材质

**古物实材质。** 出牌、结算、按钮、翻页取仙侠世界的实物声作词汇：纸张 / 竹简翻动、玉磬与铜铃、剑鸣与布帛、木鱼与石磬一类。它与视觉 UI 的「暗色扁平打底 + 古物细节点缀」对称，仙侠味由材质承载，听觉与视觉的世界感不割裂。

- **已知风险（guide 期须专项校验）：** 实材质声容易「软」，而出牌音会在一局内响几十次。出牌音在 guide 编写期须做**「几十次重复可听」专项校验**——打击感不足即回炉，不靠调音量掩盖。
- **反馈音效沿用同一套材质词汇**，只在时长与频段上与 UI 音效区分。

## 技术约束

| 约束 | 内容 |
|------|------|
| 循环 | BGM 须**无缝循环**（对局时长不定）。 |
| 静音容错 | 音频是增益，不是唯一信息通道；一切听觉信息须有视觉等价物。 |
| 混音基准 | 耳机聆听（见「动态与混音」）。 |
| 格式与预算 | _（待写：导出格式、码率、单曲时长、总包体预算——随包体预算一并定。）_ |

## 禁用清单

- 祥和国风轻音乐 / 古筝轻音乐。
- 节庆喜庆的锣鼓与吹打。
- 温馨明快的听感（对 Balatro 的规避）。
- 西式高奇幻管弦语汇：圣咏、凯尔特、铜管凯旋。
- 有词歌、旁白与配音。
- 电子舞曲律动（four-on-the-floor 一类的舞曲底鼓型）。
- 以提速制造紧张（本作靠织体加密）。
