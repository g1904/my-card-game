**意图隐藏后，玩家凭什么做出牌决策？** → 问题的前提被改写：**意图默认揭示，只有越级才降级**，且降级分三档（完整意图 → 仅类别 → 完全无信息）。信息面由三条通道共同承担：① **等级差三档揭示**（被动，由全局等级序判定）；② **探查 probe**（主动，付代价换取当回合意图；形态归内容横向扩展阶段，现搁置）；③ **敌人图鉴 EnemyCodex**（跨轮回积累的静态知识——这个敌人会做哪些事，不含本回合意图）。**「敌人状态可读」（蓄力 / 破绽等显式状态标记）的补偿方案已否决**：大幅越级就是彻底的信息黑箱，不给替代线索。（归 `systems/services/combat-service.md`、`ux/combat-ux.md`、`systems/adventure-event/combat/_index.md`、`systems/player-profile/enemy-codex/`）

**「意图通常不揭示」的例外条件是什么？** → 问题作废并反转：**不是「通常不揭示、少数例外揭示」，而是「默认揭示、越级才降级」**。判据 = 全局等级序上的「敌人 − 角色」等级差，篇章容差为第一篇章差 > 3、第二 / 第三篇章高一级即降级。「能力 / 道具授予窥视意图」保留，但归入**探查**这一条主动信息通道，而非一个孤立的例外开关。（归 `systems/services/combat-service.md`、`ux/combat-ux.md`）

**EnemyManager 内部是否还需再分职能？** → **不需要。** 敌人实例与状态、AI 行为选择、意图生成三者合一，不再细分。同时 **combat-service 新增 CharacterManager 与之平级**（两者共享大量参战方接口，差异只在驱动方式：EnemyManager 代理操作、CharacterManager 监听玩家操作），而 **DeckManager 降为参战方内部组件**（每个 character / enemy 各一个卡组，敌人也出牌）。（归 `systems/services/combat-service.md`、`_index.md`、`systems/architecture.md`、`program-overview.md`）

**mana 逐步恢复速率 / `manaLimit` 随境界成长。** → 推翻「上限 + 逐步恢复」：**战斗中每回合开始 mana 自动恢复至 `manaLimit`**（满值、不结转）。**`manaLimit` 不随境界自动成长**，而是**由 AdventureEvent 的 cost / reward 推拉**（可升可降；下降时战斗内恢复上限随之下降）。推论：mana 不再是战斗内的节奏来源，只是每回合固定的行动预算。（归 `systems/character-profile/mana.md`、`systems/adventure-event/combat/_index.md`、`systems/balance.md`、`terminology.md`）

**战斗中途断线 / 退出的处理 + 取消语义。** → **事件过程（含战斗）按决策点落存档**，退出重进恢复同一局面与同一份 RNG 状态；**`selectCost` 不回滚**（视同已结算，不退还，含 `lifeSpanCost`）。草案中「同一事件重试 < 10 次 / 篇章重试总数 < 30 次 / 超限强制 defeat」**未采纳**——其目的（防退出重试作弊）已由决策点存档达成。**重试模型依然按 ADR-0004**（∞ / 3 / 1），且**重试计数只有「每个角色的篇章重试」一种**，仅在角色进入第二 / 第三篇章后存在；第一篇章是随机生成起始角色的重试，**不能指定重试同一角色**。（归 `systems/services/life-cycle-service.md`、`combat-service.md`、`systems/character-profile/_index.md`；ADR-0004 不变）

**Finale 的独立结算规则。** → 推翻「走独立结算，而非 Combat 的战斗结算」：**大部分 Finale 是战斗的变体**，使用同一套 CharacterManager + EnemyManager 与回合循环，区别只在**独立的胜负条件与奖励结构**。**渡劫的对手 = 天劫，天劫是一个带定制卡组的 Enemy。** 少部分非战斗形态的 Finale 留待日后定制。**Practice 同样是战斗变体**，其切磋对手亦为 Enemy。（归 `systems/adventure-event/finale/_index.md`、`practice/_index.md`、`systems/services/combat-service.md`、`_index.md`）
