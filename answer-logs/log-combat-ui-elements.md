**战报条目的文案体系（承重）** → 三格全定。**与飘字的分工判据：不读也不会错过的归飘字，不读就读不懂的归战报**——飘字 = 量与归属（不承载因果与例外），战报 = 事实与例外。**收起态单行 = 结构化槽位** `[归属方] [动作动词] [来源名] · [增量]`，取「敌方打出「回风诀」 · 你 −5」这一档；**省略顺序是一条规则：优先省略来源名，绝不省略增量**。**截断量与落空以符号标记表达，括注只在展开态**（单行 + 永不换行 + 超长省略下，被省略掉的恰好是括注本身）：截断 → 增量后缀一枚溢出符；部分落空 → 来源名后一枚落空符；全条落空 → 直接写「[来源名] · 目标已不存在」。两枚符号须非数字、单字宽、互不相似，不做说明浮层。翻译键随 `CombatFeedKind` 成员机械对应，来源名作格式参数插入、不进翻译键。（`ux/combat-ux.md`、`ux/error-and-blocking-ux.md`）

**卡牌详情页的内容清单与排布** → bottom sheet、内容自适应、上界屏高 60%、超出页内滚动，**不分区、不分页、不加 tab**。七项自上而下（标题行 / 插画缩略 / 规则文字 / 次类型行 / 目标声明摘要 / 启动区 / 不可用原因），缺项整行不渲染、不留空槽；战斗内不显示 `Rarity`；关键字仍走长按二级展开、宿主换成详情页。**禁用档与战报展开态同档**（只争屏幕不争语义）⇒ 敌人回合 / 结算中可开，选目标态下入口天然不存在；三行对照表写进文档。（`ux/combat-ux.md`）

**道具区 / 神通法则条 / 埋伏标记 / 类型标识四项具体形态** → **随身** = 胶囊形角标（图标 + 数字徽章），0 件时置灰保留不隐藏；`AbilityScope` 两级标识 = 一枚形状化角标（不用文字、不用边框色），抽屉内按两级分段。**只读层** = 单行图标条 + `+N` 溢出聚合格、**不折叠为角标、不做任何滚动**；`K = floor(可用宽度 ÷ (最小触控目标 + 间距))`、硬下界 `K ≥ 3`、初值 5；溢出格内有任一可启动条目时该格带强调态；宽度不足时整条上移为战场带上沿的「己方资源条」，不得移出战场区。**埋伏** = 己方逐条渲染（折叠会失去可寻址的启动入口宿主）、对手侧固定预留位的计数（0 时淡出但占位）；两侧 0 值处置不同的判据 = **它是不是一个入口**。**卡框色 + 类型角标** = 颜色管「哪一类」、形状管「同一类」；角标须脱色后仍两两可辨；卡框色 = 细描边 + 一条较厚色带、不整框着色；`Affliction` 角标最醒目。（`ux/combat-ux.md`）

**疲劳的呈现** → 三格全定。**抽牌堆剩余张数常驻**（数字叠在抽牌堆实体上，零新增区）；**见底预警只给一档、纯静态**（`<= DrawPerTurn × 2` 转红字，不闪烁、不弹提示、不加音效、不写预警文案），阈值写成派生量而非固定张数、不进 `CombatRulesData`；**飘字侧按起飞点区分疲劳与被削减**——疲劳没有任何来源对象，飘字自抽牌堆飞出，**颜色不参与归因**。（`ux/combat-ux.md`）

**战后奖励面板的形态** → 战斗流程内的全屏一屏，三段（结果 / 强制 / 可选）+ 底部全宽主按钮。**强制段必须展示**（失败侧的额外惩罚正是以负向条目包在 reward 内，不展示等于让惩罚静默发生）；强制 / 可选靠「有没有按钮」这个结构差区分；**纵向堆叠全宽行、绝不横滑**（横滑是「择一」的语汇，而三项各自独立可领是承重语义）；已处置项**就地置灰保留**，但**两个按钮移除而不是置灰**（已成事实、无说明可给），行尾以勾 / 斜杠两个非文字符号区分已领取与已跳过；主按钮在仍有 `Pending` 时置灰并给一行说明；与事件结算面板**两屏顺接不合并**。（`ux/combat-ux.md`、`ux/error-and-blocking-ux.md`）

**敌人台词的槽位清单（`LineSlot` 的成员）** → 落点先定：**敌人立绘上方的非常驻浮层气泡**，不进任何 `Container`、约 1.5 s 淡出、不可点不可关闭、触控穿透、与既有节拍并行播放（敌人回合 ≤ 4 s 上界原样成立）。**首批五成员**：`OnCombatStart` · `OnFirstEnemyTurn` · `OnEnemyMomentumLead`（一场至多一次）· `OnEnemyDefeat` · `OnCharacterDefeat`，全部落在既有可观测时刻上。**新增成员一律追加末尾、声明顺序不表达时间轴**；**绝不给 `EnemyLine` 加权重 / 条件 / 概率**；**硬纪律：台词永不承载规则信息**。⇒ `Lines` 从「只能是空数组」解除，`systems/enemies/common-properties.md` 的唯一待决项一并关闭。（`systems/enemies/_index.md`、`systems/enemies/common-properties.md`、`ux/combat-ux.md`）
