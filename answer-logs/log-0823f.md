## 呈现形态

- **卡面是否带文字** → full art，卡面只显示 `manaCost`；规则文字、卡名、关键字定义、`Power` 明示内容全部后置到点按升起的详情页。三条既有的「卡面带文字」要求换载体不换要求。（`ux/combat-ux.md`）
- **点按与长按如何分工** → 详情入口按对象是否可拖拽分化：可拖拽用点按，不可拖拽用长按。卡牌是手牌区唯一承载拖拽的对象，长按与拖拽起手争同一段时间窗。（`ux/combat-ux.md`）
- **结算是否做滚动播报** → 不做。逐层 LIFO 弹出 + 每层短暂强调，弹完即落账；「不可暂停」读作无玩家侧暂停 / 跳过控件，不推翻中途挂起。（`ux/combat-ux.md`）
- **演出总时长硬上界的适用面** → 只约束敌人回合。该上界的论证针对完全无交互的整段观看；对称适用会在栈深大时撞天花板而只剩跳步，与「只能加速不能跳过」相抵。（`ux/combat-ux.md`）
- **ticker 与 stackHistory 的关系** → 不是两个部件，是同一份数据的收起 / 展开两个视图，合并定名战报 `combatLog`，竖屏净增 0 个区。（`ux/combat-ux.md`、`terminology.md`）
- **战报展开态的形态与范围** → 本场全部条目、按回合分组的因果树，按结算批次缩进，默认定位最新一条；不设条数上限。统一了此前三份文档「本回合完整日志 / 全量列表 / 最近 10 条」的三种口径。（`ux/combat-ux.md`）
- **战报的条目粒度** → 结算事件，不是卡牌：卡牌结算 / 触发式异能 / 疲劳扣减各占一条；目标落空是条目上的类别值 + 槽位掩码，不另立一类条目。（`ux/combat-ux.md`、`systems/services/combat-service.md`）
- **战报是否落存档** → 不落。退出重进从空开始，代价明写接受 —— 「自解释」的承担者是选目标态指令条，它不依赖战报。（`ux/combat-ux.md`）
- **战报展开态在各交互态的可用性** → 结算态随时可开且演出不停；选目标态禁用展开、保留收起单行。判据 = 是否与决策面争抢**屏幕或语义**（展开态是半屏，会遮挡栈区与合法目标）。（`ux/combat-ux.md`）
- **战报的适用面** → 双方回合都常驻有内容（此前玩家回合清空）；固定预留高度纪律原样保留，其理由与归属方无关。（`ux/combat-ux.md`、`systems/adventure-event/combat/_index.md`）
- **是否上提为跨事件类型的 `eventLog`** → 否决。战报只属 Combat，三条理由：会制造第二权威、非战斗事件没有可记的时间轴、非战斗事件里唯一值得记的恰好必须隐藏。留下纪律「一个权威、两种寿命」。（`systems/adventure-event/common-properties.md`、`terminology.md`）
- **道念显示位** → 双方各随其头像，与既有道念对比条不互斥，合称双方道念位；玩家侧新增头像位，不承担图鉴入口。（`ux/combat-ux.md`）

## 工程契约

- **`CombatFeedEntry` 与 `CardResolved` 的关系** → feed **取代** `CardResolved`，一个事实只留一条广播。连带改事件面契约总表、三处热路径论证范例与 ADR-0011 的范例名；论证不削弱反而加强（feed 覆盖四类结算，频率高于每张牌一次）。（`systems/services/combat-service.md`、`systems/architecture.md`、`decisions/ADR-0011`）
- **`Declared` / `Actual` 的载体** → 两级粒度并存：`ActionResult` 承载一次玩家动作链路的汇总值，feed 每条承载本次结算的增量值，呈现层只读 feed。依据：状态视图无法重建 `Declared`（对方剩 5 时打 8 与打 5 的快照序列完全相同）。（`systems/services/combat-service.md`、`systems/scoring.md`、`decisions/ADR-0018`）
- **因果父的字段命名** → 定名 `CauseEntryId`。经复核，栈条目既有的 `sourceEntryId` 指「载体所在的战场条目」，从不表达因果父，故这是真实缺口而非第二权威。（`systems/services/combat-service.md`、`terminology.md`）
- **「每次结算是可观测事件」的适用面** → 由敌人回合推广到双方回合，两条理由并列（敌人回合是唯一情报通道 / 玩家回合的连锁因果需可读且截断量须被说明）。（`systems/services/combat-service.md`）
- **战报条目存什么** → 结构化数据，不存已格式化字符串；翻译键在渲染期才套。（`systems/services/combat-service.md`）
