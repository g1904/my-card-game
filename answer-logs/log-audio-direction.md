## 同批记录的方向裁决（9 项 · 视同用户拍板，不占待答清单）

1. **范式取舍** = 史诗为骨 + 诡暗为色（四层配器 + 自然小调苍凉，其上叠不协和音簇 / 诡异音色 / 更多留白）。
2. **人声** = 纯音乐，无人声无配音，六类目全为纯器乐；不预留口子。
3. **混音基准** = 耳机聆听；不为手机外放打磨。**推翻既有陈述**（见下）。
4. **投入定位** = BGM 氛围优先，主题曲最先；音效方向本场锁定但打磨深度后置。
5. **战斗能量** = 常规低位压迫、鼓点克制；全配器爆发只留给 Finale，两份 guide 共享动机、密度分档。
6. **篇章推进** = 越走越空旷孤高（织体稀薄化 / 混响加深 / 音区极端化三参数拉梯度）。
7. **音效材质** = 古物实材质（纸张竹简、玉磬铜铃、剑鸣布帛、木鱼石磬）；出牌音须过「几十次重复可听」专项校验。
8. **寿元告警** = 一次性低调提示音（同上，已移出待答清单）。
9. **生成工具** = 本场不拍板，维持倾向 Suno / 语法不写死进模板；待商用条款合规核查。

## 推翻 1 项

- `art/soundtracks/audio-direction.md` 原写「**手机外放**是主要收听场景，低频基本听不见——重要信息不能只挂在低频上」→ 改为**以耳机聆听为混音基准**。全库仅此一处副本，**无对应 ADR ⇒ `decisions/` 一字未动**。代价被接受：外放玩家缺失低频层。**「静音容错」纪律不在推翻之列**——听觉信息仍须有视觉等价物，故外放缺失不构成信息缺失。
