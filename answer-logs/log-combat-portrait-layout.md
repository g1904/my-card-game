**竖屏分区的整体排布（本作压力最大的一处）** → 定为六个常驻区的屏高预算表：顶部条 5% · 敌方区 20% · 决策面板组 16%（道念对峙条 7 + 回合进度 3 + 战报收起态 6）· 己方战场带 12% · 手牌区 28% · 底部条 10% · 安全区留白 9%；栈层 / 飘字层 / 指令条 / bottom sheet 各占 0%（叠加层）。总原则「上敌下我、中轴为共享决策面板」。三个百分比是初值、须在 18:9 / 19.5:9 / 平板三档实测。**根因裁决：栈不必常驻，改为结算期临时浮层**——出牌时机是「行动阶段且栈为空」，取其逆否即玩家能动的每一刻栈必空，释放屏高约 12–15%。连带：压缩顺序改写为「敌方立绘 → 两条战场带 → 底部条，手牌区与双方道念位不参与压缩」，栈退出压缩链；「栈区保持可见且不被压暗」改写为「选目标态期间栈层必然在场且豁免压暗」。（`ux/combat-ux.md`）

**栈与战场的同屏呈现** → 三条同时成立的正交轴：**存在性**（战场恒在 / 栈只在结算期出现）· **位置**（两条常驻横带 / 中轴浮层）· **轴向**（横向 / 纵向）。不靠颜色（色觉可及性 + full art 底色不可控）。栈顶画在最上 + 「↓ 下一个结算」固定指示；栈条目半透明 + 悬浮投影 + 无底座，战场条目实心 + 贴带底 + 描边底座；**弹栈 = 一次可见的位移**（飞向战场带 / 弃牌堆 / 只读层），复用既定节拍、不新增停顿，敌人回合 ≤ 4 s 上界不受影响。（`ux/combat-ux.md`）

**道念对比的视觉形态（含「道念差是否显式呈现」）** → 形态 = **横贯屏幕的对峙条**（单条双向、中点为分界、两端各挂头像与数值），分界线位置 = `myMomentum / (my + enemy)` ⇒ 不读数字即可读出局势；固定的初始中点刻度使偏移量 = 道念差的视觉长度；数值按三位数排版。**道念差显式呈现** = 分界线上方一枚 `+15` / `−15` 徽标——它是胜负判据、奖励厚度、寿元扣减三个消费点的共同输入。**不附「≈ −N 寿元」的二级换算**（寿元不进战斗屏，该子项已独立否决）。⇒ 本项不被 `lossPerMomentum` ch2 / ch3 未定案阻塞。**回合进度与道念差取空间邻接、不合成复合指示**——合成需要一个待校准的期望产出模型，且会替玩家算掉那本账。（`ux/combat-ux.md`）

**战斗屏幕的其余形态整体未设计（手牌布局 · 敌我分区 · 敌方出牌的呈现）** → **手牌** = 水平重叠扇（不做弧形旋转）、≤4 张不重叠、5–7 张每张至少露出左侧 40% 宽度、区高固定、拖起时上浮 + 放大 1.1× + 描边、拖拽阈值以一条释放线可见化、满手抽不进 = 抬起一半后退回抽牌堆、上限常驻形态 `n/7`。**敌方区不做己方的镜像**（只承载读数与观看；手牌只给张数角标，不渲染牌背扇形；埋伏只给计数角标）。**敌方出牌在立绘前方放大呈现一拍（0.35–0.5 s）再落入栈层**——full art 无卡名无规则文字，缩略一闪等于取消唯一的动态情报通道。另定**结束回合键**（底部条右端主按钮、不做二次确认、三态置灰）与**回合进度形态**（`TurnLimit` 个小格 + 并列文字，格数由遭遇配置驱动、绝不写死 10；当前格着色即「轮到谁」）。（`ux/combat-ux.md`）

**牌堆在竖屏战斗屏上是否有稳定可见面（`07-codex-monetization.md` 的事实确认）** → **有。** 抽牌堆 = 底部条中部一叠牌背朝上的牌，厚度随剩余张数递减；弃牌堆并列、面朝上显示最近进入的那张；**敌方牌堆不给实体**。⇒ **卡背的可见面 = 玩家侧抽牌堆顶 + 己方埋伏背面**，卡背品类解除阻塞。落地时须在 `art/visuals/` 资产类目表新增「卡背」一行（归内容 / 美术排期）。（`systems/monetization.md`、`ux/combat-ux.md`）

## interview 裁决（批量评审 · 两项 + 三项标准默认）

**Q1 栈是否改为结算期临时浮层？** → **A · 浮层化。** 依据是纯规则推演而非排版偏好；屏高预算表按推荐值成立，`ux/combat-ux.md` 的两句措辞（压暗豁免、压缩顺序）随之改写。

**Q2 敌方立绘在屏高中的分量？** → **A · 紧凑半身像，敌方区 20%。** 浮层化释放的 12–15% 全部流向手牌区与己方战场带。依据：敌方区本就是压缩顺位第一，且敌人立绘在战斗前确认页已有一次充分呈现。

**标准默认（未出题，直接落笔）：** ① 卡面必读元素占位 —— 重叠扇每张恒只露出左侧 40% ⇒ `manaCost` 左上角、类型角标紧邻其下、卡框色带落左边缘，右上角不承载任何必读元素；② 结束回合键成立（属文档缺口而非取向）；③ 敌人台词气泡按姊妹草稿的口径（立绘**上方** / ≈**1.5 s**）。
