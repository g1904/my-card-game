## 移出（2 全条）

**guide 的粒度：一个内容条目一份 guide，还是一个类目一份 guide + 逐条目只填变量？**
→ **类目 guide + 条目变量**（轴 9）。一个资产类目一份 guide，承载公共段（风格、构图规范、参考素材、prompt 骨架、参数）；逐条目只填主体 / 构图 / 情绪三个变量。稳定性优先——分次生成的最大风险是风格漂移，共享公共段是唯一收敛手段。表达力缺口由**例外升格**通道兜住：少数需特殊表达的条目（Finale 敌人、关键角色）可升格为独立 guide，但**必须在所属类目 guide 的「例外升格」表中登记指针**，否则两份 guide 各自漂移且无机制发现。
→ 归档去向：`art/visuals/_index.md` 的「承重约定」·`art/visuals/guides/_TEMPLATE.md`（按公共段 + 条目变量段重组）· `art/visuals/guides/_index.md`（命名与粒度约定）。同批从 `art/visuals/_index.md` 的待决区移除。

**UI 元件是否走 AI 生成？**
→ **混合路径**（轴 8），切分线与 UI 材质隐喻（轴 7：暗色扁平打底 + 古物细节点缀）一一对应：**扁平底子**（面板 / 按钮底 / 容器 / 状态变体 / 九宫格切片）由人工 / 矢量制作，**不进 AI 流水线、不建 guide**——它本就是纯色块与描边，整图生成无增益却要承担九宫格与状态变体的全部风险；**古物点缀素材**（符纹 / 印泥 / 纹样 / 边角装饰）走 Midjourney 生成后裁切入 UI，正常建 guide。故 UI 类目的 guide 只覆盖一半。

## 同批裁决（不占清单条目 —— 用户在 `/design-direction-interview` 中亲口拍板，本技能按定案提炼）

七条方向裁决，落 `art/visuals/art-direction.md`：

1. **绘画质感** = 厚涂写实为主 + 水墨作氛围点缀（不作主体语言）；否决浓水墨 / 国画感与风格化混合。
2. **残酷尺度** = 压抑由氛围承载（色彩 / 光照 / 残垣 / 枯骨远景 / 荒芜 / 神态），**不画血腥特写与恐怖直给**；gore / 断肢一类进每份 guide 的禁用词；**不预留上调口子**。
3. **色彩策略** = 三层（暗基调公共板 + 地域色相签名 + 主体焦点高对比）；全局色板**不随境界推移**——境界感已由「按条目叙事定位取沉」承担，色板绑章会与条目跨章复用（`EncounterScopes`）打架。
4. **人物美型度** = 写实英气（写实、有英气与美感，不锐化美型不卖萌不扮丑）；角色形象与敌人立绘两类目共用；否决「美型为底 + 残酷点缀」与 40k 式粗粝。
5. **光照性格** = 冷光主调（阴天漫射 / 冷月光）+ 灵光点缀（法术 / 符箓 / 丹炉的局部暖与异色）；否决烛火暖光主调与戏剧性硬光。
6. **卡框色语汇** = 仙侠意象色，**不套五行**（五类与五行无语义对应，硬套会诱导玩家找不存在的相克关系；未来引入灵根 / 属性系统会撞车）；**意象服从可辨性**，色相在满足三条机械约束的候选中挑。**只锁语汇、不代取值。**
7. **UI 材质隐喻** = 暗色扁平打底 + 古物细节点缀落边角；否决拟物古物材质与水墨笔触 UI。
