## 逐条

**`.claude/rules/*` 中夹带的设计性表述如何处理——是「一句话承重纪律 + 回链」的合法形态，还是应进一步瘦身？边界判据是什么、由谁执行？**（`open-questions/05-service-contracts.md` 第 2 条 · 同题条目亦在 `systems/common-properties.md` 的 `## 待决问题`）

→ **形态合法，不瘦身到纯链接；补上量化阈值与执行者。**

- **① 依据不是折中，而是加载模型差异。** `knowledge/*` 是 Claude **主动去读**的（读它的那一刻本就在找东西，多跳一次即可）；`rules/*` 是**前置注入**的，它要在 Claude **还没有理由去读设计库时**就改变写法——纯链接在注入层失效，因为写错代码的那一刻往往正是「没觉得需要查」的那一刻。ADR-0005 原文对两者措辞不同（「只留链接」vs「一句话 + 回链」）不是笔误，本次是把后者**量化**，不是放宽。
- **② 两步判据。** 第一步归属分类（讲「游戏是什么」→ 受约束；讲「代码怎么写」→ rules 自身即权威，写多长都不算副本；讲引擎 / 语言实践 → 设计库无权威，同 `standards/` 三份的处理）。第二步投影**四件套**：一句祈使 + 标识符名 + **一句代价说明**（删掉它这条就退化成可商量的口味）+ 一条回链，缺一不可、多一即越界。
- **③ 硬边界七条（可机械检查）：** 代码块 · 表格 · 枚举 / 字段清单（两个以上并列成员名）· 具体数值 / 阈值 / 默认值 · 完整取值域或分支穷举 · ≥3 步编号流程 · 超过 3 行。理由与 08-14 判据卡逐字同构（两份表各自漂移而本库无机制发现不一致）。另附三条机械规则：**回链直指设计库不经 `knowledge/` 中转**（该层自己也是薄引用 ⇒ 二跳且多一个失效点）· **已被阶梯第 1 / 2 级强制的纪律只留一句「由 X 强制」+ 回链**（编译器已在强制时，条款属第 4 级零保证投入且是漂移源）· **无回链的设计性表述一律违规**（缺回链与「还没想」不可区分）。
- **④ 执行者 = 扩 `/sync-knowledge` 的对账范围到 `.claude/rules/*`**（技能**不更名**，改为在描述与正文首段写明对账对象 = 整个 `.claude` 的设计投影面）。判据来自阶梯本身：本纪律只在文档层显形且违反后会累积，属第 3 级——文档没有编译期，其等价物就是一个会定期跑的对账技能。**留在第 4 级已被实证证伪**：`state-save-rules.md` 写着 `relic` / `ante` / `楼层` 三个本作不使用的泛体裁词、类型名与既定的 `CycleStateManager` 不符——ADR-0005 预言的「副本 = 下一次漂移的唯一来源」的现场。**否决新开 `/audit-rules`**（两份高度重复的技能文本各自演化，正是本判据反对的第二权威）；**否决不设执行者**。
- **⑤ 唯一显式例外：`design-library-routing.md` 的两库结构表**保留并标注为「**路由用副本**」——它复述的是目录结构（工程层路由，不是「游戏是什么」），且是技能执行的前置信息；换成回链等于每次跑设计流水线技能都要先读两份 README，而路由判错的代价是把一侧的意图写进另一侧的库。标注使它成为已知的、有理由的、被审计覆盖的副本。
- **⚠ interview 一项：判据定义的落点。** 草稿步骤 1 写「`common-properties.md` 追加判据卡（~10 行）」，步骤 2 又要求「定义与投影二选一，两处不得各写一遍硬边界清单」——两句自相矛盾。**裁定：定义写 `decisions/ADR-0005` 新增的「### 2. 规则层的具体形态」，`common-properties.md` 只写 ≤5 行投影 + 回链。** 依据：ADR-0005 是这条判据的最小公共祖先（它已持有总纲那句「一句话承重纪律 + 回链」），且 `common-properties.md` 该小节现状本就是投影形态，追加 10 行判据卡会把它变成第二权威。
- **边界：** 净瘦身约 15~20 行、**无任何工程约束条目被删**；设计库中 5 处 `Source: .claude/rules/*` 的指认（稳定 `Id` 键 / 字段命名与类型一致性 / Null 校验 / 日志约定 / 原子写入）全部属工程约束、**全部保持有效，不反转任何一处方向**。**不改机制 / 字段语义 / 存档 schema / API 签名，不 bump schema，无迁移，对 `backend-design-documents/` 零影响。**
- **一项有时间性但不阻塞（仍在 handoff 的 Open questions 中）：** 规则 b 对 `AllEnabled()` 的完整效力要等 `DrawPool<T>` 与仓储接口落地（已排期，与 `LocalizedText` 同批）；在那之前按硬边界压到 3 行即可。
