# 收件箱 — 草稿

- 道念差 = lifeTotal loss
- 通常输了就只有 baseReward, 少部分情况会有额外惩罚（包在 reward 里面）。
- combat-service 按照结果计算，获取奖励属于 combat 流程的一部分。
- 部分奖励是强制必须的（会自动计数，比如经验），另外一些可选项由玩家选择（类似 sts）
- 卡牌产 / 削道念的量纲基准 = 在内容横向扩展的时候会具体定义，届时会在设计 起始角色的 starter deck 过程中聚焦并定义 ch1 的数值标杆。
- 越级追分是可能的，尤其是大境界的差距，会很难，因此 baseMomentum 差距变大。
- 道念字段 = momentum, >=0 的 Integer。
- Finale / Practice 的道念规则差异: finale 的 胜负条件 和 回合数可能变化，相比 combat 会更难，practice 的 胜负条件 和 回合数 可能变化，相比 combat 会简单。标准的 combat 是 10 回合，以道念差判断胜负。
- 可以这么理解：practice = balatro small blind; combat = balatro big blind; finale = balatro = boss blind.
- lifeTotal 的恢复幅度 会在 内容横向扩展的时候会具体定义
- 内容横向扩展的时候会需要一个专门的 ch1 数值模型 session
- 优先打磨 ch1 的内容。
- 卡牌结算方式参考 magic the gathering 'stack' concept.
- I will be using a lot of mtg terms in the future to simplify the card/deck/combat system.
