# ADR-0220 — 选择区卡宽恒定、逐项吸附、按常态 3 项同屏标定；N 变只改「要不要滑」

- **状态：** Accepted
- **日期：** 2026-09-08
- **来源：** handoffs/2026-09-08-portrait-option-list.md · answer-logs/log-portrait-option-list.md

## 背景

批次规模 N ∈ 1–5，若卡随 N 缩放，同一张卡在不同批里大小不一，会与 Explore 遮罩卡的等宽节奏直接相抵。

## 决策

**EventOption 选择区 = 横滑等宽 carousel，1–5 项自适应七条规则 R1–R7**：卡宽 / 卡高跨批恒定不随 N 缩放 · 标定基准 = 常态 3 项恰好同屏 + 左右 peek · N ≤ 3 不可滚动（回弹）· N = 4 / 5 逐项吸附 · N ≥ 4 给 N 枚位置点 · N = 1 与多项批完全同形且不加说明文案 · 闸门批复用同一选择区零特殊形态。

**六个手感参数的旋钮位置 = 呈现层常量的 `[Export]` 字段**，不进数据资源 / 存档 / 内容条目。批次规模读 `EventOptionBatch.Options.Count`，**不读 `BatchSizeWeights`**。

## 理由

`ux/screen-flow.md`：跨批缩放会让同一张卡在不同批里大小不一，**读成「这批更重要」**，且与 Explore 遮罩卡「同尺寸、同触控目标、同滑动节奏」的等宽节奏直接相抵。

呈现面零数据增量：`EventOption` 零新增字段。

## 备选方案

- **卡宽随 N 缩放 / 异形卡** — 否决：理由如上。
- **自由惯性滚动** — 否决：会让玩家滑过头、失去「一共几项」的把握。

## 后果

- 约束 N 变只改「要不要滑」，绝不改卡的尺寸与形状。
- 六个手感参数落 `[Export]`、**不受 overlay 管辖**——它们不是平衡数值，改它们不改任何玩法结果。
- 放弃了按 N 优化屏幕利用率；实测校准项已登记在 `ux/screen-flow.md`。
