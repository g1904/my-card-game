# ADR-0205 — 道念差显式呈现为一枚 `+15` / `−15` 徽标，不附寿元换算

- **状态：** Accepted
- **日期：** 2026-09-08
- **来源：** handoffs/2026-09-08-combat-portrait-layout.md · answer-logs/log-combat-portrait-layout.md

## 背景

「道念差是否显式呈现」长期悬着。反方论据是「差换算成寿元还要先乘一个逐章系数，显示了也不等于玩家知道后果」。

## 决策

**道念 = 单条双向对峙条**，分界线位置 = `myMomentum / (my + enemy)`（不读数字即可读出局势），数值按**三位数**排版。

**道念差显式呈现 = 分界线上方一枚 `+15` / `−15` 徽标（带方向色）。**

**不在差值旁再附一层 `≈ −N 寿元` 的二级换算**——寿元不进战斗屏。

## 理由

`ux/combat-ux.md`：道念差是**胜负判据、胜侧奖励厚度、负侧寿元扣减三个消费点的共同输入**；ch3 战中可达三位数，要求玩家自己做三位数减法不符合「明快、单手」的基调。

而「换算成寿元要先乘一个逐章系数」削弱的是「差 → 寿元」这一步，**不是「差本身要不要显示」**。

## 备选方案

- **不显式呈现（只给两端数值）** — 否决：理由如上。
- **显式呈现 + 附二级寿元换算** — 否决：寿元不进战斗屏。

## 后果

- 约束数值排版按三位数设计（四位数是寿元口径，不在本屏）。
- 放弃了战斗屏内的寿元换算读数。
