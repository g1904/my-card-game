# ADR-0251 — 语义 → `(Stat, Direction, Grade)` 是一张编排判据表，不是校验；`Travel` 一律不填且不立加载期校验

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09f-event-reward-and-hidden-stat-orchestration.md

## 背景

`HiddenStatGrant` 挂在事件选项的产出侧，任何事件类型都能携带。但「哪种语义该推哪个属性、往哪个方向、推多大」此前没有口径——逐条目全凭编排者直觉，五类事件之间必然漂移。

## 决策

**立一张覆盖五类事件的编排口径表**，把语义映到 `(Stat, Direction, Grade)`。**它是编排判据表，不是加载期校验。**

**配三条编排纪律：**

1. 一个条目**至多两条 grant**；**默认动作是不填**。
2. **`Travel` 一律不填**——**以 `/audit-content` 的汇总项看住，不立加载期校验**。
3. **`Explore` 壳不填、真身填。**

→ `systems/adventure-event/common-properties.md`。

## 理由

- **默认不填**：隐藏属性是叙事印记，处处都推等于处处都不推。
- **`Travel` 不填有两条理由**：换图**没有道德内容**；且它已因不占事件位而少一道软闸，再开一条隐藏属性通道即开出**来回横跳刷道心**的口子。
- **`Travel` 那条不立加载期校验是承重的**：「允许面对五类无一例外开放」是结构结论，**加硬校验即在结构上推翻它**。审计汇总项能看住编排失误，而不改变结构承诺。
- `Explore` 壳不填、真身填，与「Explore 的真身才是实际发生的事件」这一既定物化形态一致。

## 备选方案

- **把语义映射写成加载期校验** — 否决：语义无法被机械判定，校验只能退化为形式检查。
- **给 `Travel` 立加载期校验禁止 `HiddenStatGrants`** — 否决：在结构上关掉「五类一律开放」这条既定形态。

## 后果

- 审计汇总项单列**「`Travel` 条目携带推拉」与「`Explore` 壳条目携带推拉」两项异常**（只报告不阻断）。
- 判据表是**编排口径**，不落任何字段、不 bump `schemaVersion`、后端零参与。
- 逐条目的具体映射仍归内容编排，本表只给判据。
