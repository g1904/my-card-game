# ADR-0052 — 抽牌堆不重洗，抽空即疲劳；卡组规模两侧皆不设硬限

- **状态：** Accepted
- **日期：** 2026-08-11
- **来源：** handoffs/2026-08-11c-combat-turn-flow-fatigue-and-card-type-reduction.md, handoffs/2026-08-22-enemy-deck-size-and-fatigue-knob.md

## 背景

对局必须终止。常见做法是重洗弃牌堆继续抽——但那样对局可以无限延长，且「卡组变大」变成纯粹的收益（更多选择、无代价）。

另一侧，`enemies/common-properties.md` 曾写「样本卡组规模 15」，与全库其余六处「不设硬限」的表述冲突，需收口。

## 决策

**抽牌堆不重洗，抽空即疲劳（承重）。** 弃牌堆不回流；**抽牌堆为空时每尝试抽一张牌，抽牌方失去 1 点道念**。

**卡组规模两侧皆不设硬限**（玩家与敌人同规则），其代价**由疲劳承接**。敌人侧的唯一硬校验是「样本卡组并集为空必是漏填」与「不得含 `Pool == Character`」。

疲劳扣减量保留为**全局常量**，不升格为 per-encounter 覆写。

规则 → `systems/services/combat-service.md`；敌人侧校验 → `systems/enemies/common-properties.md`；数值 → `systems/balance.md`。

## 理由

删除重洗是疲劳能够存在的前提——有重洗则疲劳永不可达。而疲劳一旦存在，卡组规模就自带代价曲线：卡组越大越晚疲劳、但关键牌越稀，玩家自己去权衡。**规模因此不需要硬限**，也不是可机械校验的量。

疲劳扣减不升格为覆写，是因为它**没有覆写基准可拧**——它是一条全局节奏参数，per-encounter 覆盖它等于让每个遭遇各有一套终局速度。

## 备选方案

- **重洗弃牌堆** — 推翻（08-11c）：疲劳永不可达，对局无终止压力。
- **敌人卡组固定 15、作为物化旋钮** — 推翻（08-11c 连带）：与全库六处表述冲突，且规模不可机械校验。
- **疲劳量升格为 per-encounter 覆写** — 否决（08-22）：无覆写基准。

## 后果

- 「卡组规模是一条疲劳编排旋钮」成立，这是敌人构筑面保留游离散牌一格的理由（→ `ADR-0090`）。
- 疲劳以栈条目结算（→ `ADR-0088`）；规则本身（不重洗、每抽 −1 道念）不变。
- 对局终止性另有 `EncounterSpec.TurnLimit` 作硬护栏。
- **边界：本决策否决的是「抽牌堆空时由弃牌堆回流重洗」这条规则性、无限次的补充机制；有限次、消耗性的一次性效果把牌置于抽牌堆顶 / 底是允许的。** 判据是终止性压力：规则性重洗使疲劳**永不可达**，而一次性效果只把疲劳推后有限次抽牌，失血曲线的形状不变。护栏落在**载体的消耗性**上（法术结算即进弃牌堆、道具须有限充能、启动式异能有配额闸、静止式异能在结构上装不下原子操作）与 `TurnLimit` 这条硬护栏上，**不落在「能不能回堆」这一问上**。形态、目的地与逐条校验见 `systems/services/combat-service.md` 与 `systems/character-profile/deck/common-properties.md`。
