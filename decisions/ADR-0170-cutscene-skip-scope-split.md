# ADR-0170 — 演出跳过权按作用域分档：战斗外可跳过 / 可快进，战斗内不可跳过

- **状态：** Accepted
- **日期：** 2026-09-06
- **来源：** handoffs/2026-09-06-stale-wording-roundup.md · answer-logs/log-stale-wording-roundup.md

## 背景

两份文档对「演出能不能跳过」给出相反的话：`art/visuals/animations/_index.md` 写「须可跳过 / 可快进」，`ux/combat-ux.md` 写「只能加速不能跳过，『逐步可见』是硬要求」。前者写于占位期、无论证；后者是 `ADR-0086` 把结论写进决策本体并带承重论证的那一条。但直接裁给后者会推出「全游戏一律不可跳过」——而那条论证的前提（敌人回合是唯一动态情报时刻）在战斗外根本不成立。

## 决策

**跳过权按作用域分档：战斗外的演出默认允许跳过 / 快进；只有战斗内的结算演出不设玩家侧跳过控件。**

战斗内维持既有形态不变：点按屏幕任意处 3× 加速，**只能加速不能跳过**。

战斗外跳过控件的统一形态（触点、是否记忆偏好）作为承接项留在 `art/visuals/animations/_index.md`，随该分区产出 animation guide 时定。

## 理由

- **`ADR-0086` 的论证前提在战斗外不成立**：那条硬要求的理由是「逐层 LIFO 弹栈是玩家读懂结算的唯一通道」，而战斗外的转场不承载任何需要逐步读出的状态变化。
- **轮回制下同一段转场会被重复观看数十次**，不可跳过会直接侵蚀 `vision/scope.md` 的篇章时长预算——而时长预算刚被重新标定（`ADR-0164`），每一分钟都是算出来的。
- **裁给 combat-ux 侧而非 animations 侧**：前者的结论有承重论证并已进 ADR，后者写于占位期。作用域分档是在**不推翻前者**的前提下让后者的合理部分成立。

## 备选方案

- **全面不可跳过**（把 combat-ux 的口径推广到全库） — 否决：把一条有前提的硬要求当作无前提的通则，且直接与时长预算相抵。
- **全面可跳过**（把 animations 的口径推广到战斗内） — 否决：推翻 `ADR-0086` 的承重结论，且「逐步可见」是玩家读懂 LIFO 结算的唯一通道。

## 后果

- **`ADR-0086` 的战斗内结论一格不动**——本条只界定它的作用域边界，不改写它。
- **战斗外跳过控件的具体形态未定**，是一条已登记的承接项，不是本条的遗漏。
- 受约束的文档：`art/visuals/animations/_index.md` · `ux/combat-ux.md` · `decisions/ADR-0086-lifo-resolution-and-combat-log.md` · `vision/scope.md`。
