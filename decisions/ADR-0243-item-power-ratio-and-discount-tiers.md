# ADR-0243 — `itemPowerRatio` 的「不占手牌位」溢价上调至 ×1.15，四档折价整体下移 0.03

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09d-combat-rarity-and-reward-scale.md

## 背景

跨载体边界判据用一张按代价排序的表把卡牌 / 法宝 / 神通放在同一把刻度上（→ `ADR-0152`）。其中「法宝相对卡牌的溢价」由两项构成：不占手牌位、使用时机确定。第一项此前留了一个 1.15–1.20 的建议区间未定。

## 决策

**「不占手牌位」溢价定为 ×1.15**（取建议区间的下沿）⇒ 与「使用时机确定 ×1.15」合计 ≈ **×1.85** ⇒ 等价折价 ≈ 0.54，**四档折价整体下移 0.03，定为 `0.52 / 0.62 / 0.72 / 0.87`**。

另两项溢价不动。→ `systems/balance.md`。

## 理由

**手牌上限 7 是「紧但不是每场都咬」的约束**——规避它的溢价因此应取区间下沿，而不是把一个偶尔生效的约束当成常态压力定价。

## 备选方案

- **取区间上沿 ×1.20** — 否决：高估了手牌上限的实际咬合频率。
- **保留区间不定案** — 否决：四档折价因此永远算不出，跨载体表无法用于内容评审。

## 后果

- 四档折价的具体取值成为跨载体内容评审的对照基准，逐条目定价直接读它。
- 该取值随手牌上限或弃牌机制的任何改动一并重估——它是从那条约束推出来的，不是独立旋钮。
