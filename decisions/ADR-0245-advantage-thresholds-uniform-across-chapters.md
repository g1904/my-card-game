# ADR-0245 — `advantage` 三档边界三章恒 `0.25 / 0.75`，不按篇章分格

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09d-combat-rarity-and-reward-scale.md · answer-logs/log-combat-rarity-and-reward-scale.md

## 背景

优势档由 `advantage = 道念差 / max(1, 角色 baseMomentum)` 分三档（险胜 / 优胜 / 碾压）。篇章推进会整体抬高量纲，因此存在一个问法：三档边界要不要按篇章分格，以维持三章的档位分布大致相当。

## 决策

**三档边界三章恒 `0.25 / 0.75`，不分格。**

ch1 的品质偏厚是**有意的取向**；总量已由挂池占比在数量侧压住（→ `ADR-0240`）。→ `systems/balance.md`。

**连带一条纪律读法的订正：** `ADR-0163` 明写随进度的分格轴恰有两条（全局等级序 1–22 与篇章 ch1–ch3），须先立 ADR 的是**第三条**轴 ⇒ 「按篇章调三档边界须先立 ADR」是**过严表述**，篇章本就是允许的分格轴之一，要分格只需落表 + 登记。

## 理由

**ch1 品质偏厚与渐进式复杂度 / 早期正反馈同向**——新玩家在第一篇章多拿到几件好东西，正是想要的手感。

而分格会引入一张三章各异的边界表，为的只是把一个**有意为之**的偏置抹平。

## 备选方案

- **按篇章分格三档边界** — 否决（用户裁决）：抹平一个有意的早期正反馈，换来一张新表。

## 后果

- **代价明写并接受：ch3 的碾压档接近不可达。**
- `ADR-0163` **未被改动**——被改的是主题文档里那句过严的转述，不是决策本身。
- 日后若要给三档边界分格，走「落表 + 登记」即可，不需要新 ADR；需要新 ADR 的仍然只是**第三条分格轴**。
