# ADR-0175 — 失败容错量标定为 N = 2、三章统一，「典型失败」五格口径锁死

- **状态：** Accepted
- **日期：** 2026-09-06
- **来源：** handoffs/2026-09-06-failure-spiral-tolerance.md · answer-logs/log-failure-spiral-tolerance.md

## 背景

寿元是唯一的压力线，失败按道念差扣寿元（`ADR-0018`）。但「一个篇章里输几场还能走完」这个量从未被标定——没有它，寿元预算、`lossPerMomentum` 与回寿通道三者的取值互相说不清，也没有任何可验收的断言。更麻烦的是，「一次失败」本身没有定义：不同档位、不同道念差的失败扣减相差数倍。

## 决策

**失败容错量 N = 2，三章统一。**

**「典型失败」的五格口径锁死：** `Combat` / `Standard` 档 · `diff = 0` · `E[道念差]` = 5 / 12 / 18 · `lossPerMomentum` = 10 / 5 / 10 · 经验按 `Major` 折半。**分布口径为均匀散布**——N 次失败均匀散布在本章常规事件段，不集中在末段。

**N 不进 `.tres`、不进任何 `Resource`**：它是**标定台账与验收口径**，承重产物是**口径与反推式**，`N = 2` 是该式在当前输入下的输出。

反推台账、五格表与两层验收断言 → `systems/balance.md`。

## 理由

- **不定义「典型失败」就无法标定容错量**：五格口径把一个模糊的「输一场」钉成一个可算的扣减值，反推式才有输入。
- **N 是输出不是输入**——把它写成 `.tres` 字段等于让一个推导结果获得独立的可调性，运行期又没有任何消费者读它。
- **三章统一**：缺少分章的理由；三章的差异已由 `E[道念差]` 与 `lossPerMomentum` 逐章不同吸收。
- **均匀散布**是最不利也最诚实的分布假设：集中在末段会让容错看起来更宽（前半段的回寿还没花掉）。

## 备选方案

- **分章给不同的 N** — 否决：缺分章理由，差异已被下游两格吸收。
- **N 做成 `.tres` 字段** — 否决：运行期无消费者。
- **连败递减阻尼**（输得越多扣得越少） — 否决：`ADR-0018` 已否决同类的上限截断，且引入须存档的连败计数器。
- **「典型失败」定义为 `Practice` 档** — 否决：系统性低估容错需求。
- **N 按百分比表达** — 否决：验收动作是整数场次。

## 后果

- **验收分两层**：表侧断言 A1–A3，编辑器侧固定 seed 三读数——**不要求新增任何调试面板**。
- **「一次典型失败恒占本章预算 ≈5%」是派生锚而非独立锚**，改 N 或改五格口径即须重算，不得单独引用。
- **本条与 `ADR-0164` 共用同一批反推输入**：篇章时长一改，N 的反推式须整链重跑。
