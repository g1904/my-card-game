# ADR-0224 — UI 元件的制作路径按材质分两半：扁平底子人工做，古物点缀走 AI

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09-art-direction-nine-axes.md · answer-logs/log-art-direction.md

## 背景

`art/visuals/_index.md` 长期挂着一条待决项：UI 元件与框架这一类目走不走 AI 流水线。整类目走 AI，九宫格拉伸与状态变体全部要承担生成不稳定的风险；整类目不走 AI，则符纹、印泥、纹样一类离散装饰要人工逐件画，而那恰是生成工具最省成本的一段。

这条待决卡住的是首批 guide 的编写顺序——不知道哪一半要建 guide，就写不出类目清单。

## 决策

**UI 元件与框架分两半走两条路，切分线与「UI 材质隐喻 = 暗色扁平打底 + 古物细节点缀」一一对应：**

- **扁平底子**（面板、按钮底、容器、状态变体、九宫格切片）—— **人工 / 矢量制作，不进 AI 流水线、不建 guide**。
- **古物点缀素材**（符纹、印泥、纹样、边角装饰）—— **走 Midjourney 生成后裁切入 UI，正常建 guide**。

其余全部资产类目照常走 AI 流水线。分工表与理由 → `art/visuals/_index.md`「承重约定 · 制作路径」；材质隐喻本体 → `art/visuals/art-direction.md`「UI 元件的材质隐喻」。

## 理由

扁平底子本就是纯色块与描边，**整图生成没有增益，却要承担九宫格拉伸穿帮与状态变体逐个重生成的全部风险**；而离散的装饰素材是 AI 低成本产出的甜区，裁切入 UI 后不参与拉伸，风险为零。

切分线取「材质」而非「资产类型」，是因为材质隐喻这条既定视觉规则本身就把 UI 分成了这两半——沿用它，两份文档不会各自漂移。

## 备选方案

- **整类目走 AI 流水线** — 否决：九宫格与状态变体的风险无法被 prompt 收敛。
- **整类目人工制作** — 否决：放弃点缀素材这一段的成本优势，且与其余类目的流水线纪律不一致。

## 后果

- **UI 类目在资产类目表里只有一半走 guide**，`art/visuals/_index.md` 的类目表须如实标注这一点，不得写成整类目建 guide。
- 扁平底子的产出不进 `art/visuals/guides/`，也不受 guide 模板约束；它的规范落在 `art-direction.md` 的 UI 材质一节。
- 生成工具的正式选型（Midjourney 的商用授权与合规口径）仍是待答项，挂在 `art/_index.md`；本条只定路径分工，不构成对工具的拍板。
