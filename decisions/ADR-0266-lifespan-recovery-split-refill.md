# ADR-0266 — `R_c` 两格按实际可供给重填；回代式的 `P` 必须含「档内命中回寿子集」那层条件概率

- **状态：** Accepted
- **日期：** 2026-09-10
- **来源：** handoffs/2026-09-10-item-family-supply-guardrails.md · answer-logs/log-item-family-supply-guardrails.md

## 背景

`R_c` 已拆成事件侧 / 道具侧两格书写（→ `decisions/ADR-0246-lifespan-recovery-budget-split.md`），但道具侧那格的回代式漏了一层条件概率：商店抽取是**先按 `RarityTier` 权重选档、再在档内等概率取条目**，而回寿只编排 Tier2 / Tier3 / Tier4 三档。少乘这一层把 `p(单槽为回寿)` 高估了约一倍，两格的分账因而失真。

## 决策

**回代式的 `P` 必须含那层条件概率**：一个槽位要是回寿法宝，须**先**抽中 Tier2 / Tier3 / Tier4 之一，**再**在该档内命中回寿子集。

**`R_c` 两格按实际可供给重填**，Σ 恒等于 `R_c` ⇒ **λ 与 21 格 `lifeSpanCost` 定价表零改动**。`R_event,c` 三章统一表述为「每章 1 次小档（5% × 本章预算）+ 点名给回寿法宝的事件产出补足至本格」，三章用同一种承接、**不加 ch3 例外**。

配套的两条否定：**不新增 Tier5 回寿档**、**不推翻「Tier1 / Tier5 留空不编排」**、L-1 占比上限 6% 不动。

具体数字与回代台账见 `systems/balance.md`「回寿法宝的供给回代」（**本 ADR 不复述数值**）。

## 理由

`systems/balance.md`：**「典型档位点数」由权重表决定，不由池成分决定（承重）** —— 混合池上只按 `RarityTier` 加权抽，某一档的抽中概率就是权重表给的那个数，与该档在池里有几条条目无关（只要非空）。故回寿档只编排三档时，必须以这三档权重为条件概率反解。

缺口转给事件侧而非抬道具侧供给：**把回寿条目往高稀有档集中是反向的** —— 遇到率的跌幅大于单次点数的涨幅，极端情形（只编排 Tier4）下 `R_item,3` 反跌。

三章统一承接而不给 ch3 开例外：三档百分比「三章统一」（小档 = 本章预算 5%）不动，Σ 才能严格守住，λ 与定价表才真的零改动。

## 备选方案

- **新增 Tier5 回寿档抬道具侧供给** — 否决：与「Tier1 / Tier5 留空不编排」相抵，且往高档集中适得其反。
- **上调 L-1 的 6% 占比上限** — 否决：那是回寿族的池占比护栏，为补一个标定失误而松护栏是本末倒置。
- **ch3 改为 2 次回寿小档** — 否决：与「三档百分比三章统一」相差 +20%，会让 Σ 守不住。

## 后果

- **被接受的表述代价：** 字面上 ch3 是「1 次事件 + 1 次点名产出」而非「2 次回寿事件」。
- **⚠ 三个标定假设（败率 · `E[道念差]` · 购买转化率）未实测**，重填后的数字与期望遇到次数**不得被引为任何设计的承重依据**；回寿三档绝对点数实测后，两格一并复填。该 ⚠ 注记在 `systems/balance.md` 原样保留、不删不弱化。
- `decisions/ADR-0246-lifespan-recovery-budget-split.md` 的两格书写口径与 Σ 不变式**原样成立**，本条只改这两格的填法与回代式。
