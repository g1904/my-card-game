# ADR-0232 — 五行各持一个主战斗动词：一灵根一动词、互不重复；纯编排口径，无规则后果

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09b-combat-feel-identity.md

## 背景

灵根的**唯一规则后果是功法修习准入**（→ `ADR-0123`），五行之间没有任何相生相克。但五份灵根小池的功法要分头立项，需要一根能把「这门功法属于哪一行」讲清楚的骨架——否则五个池的内容会长成同一堆东西，角色辨识度无从谈起。

## 决策

**五行 → 主战斗动词映射：**

- **金** = 锋锐削拆（反制主承载）· **木** = 生长滚雪球（阵法运营）· **水** = 绵长连锁（触发链 / 抽牌）· **火** = 直接爆发（大额产出、高方差）· **土** = 厚重稳固（护阵 / 低方差稳定产出）。

**一灵根一主动词、互不重复。**

**这是编排口径而不是规则**——五行之间仍没有任何相生相克，灵根唯一的规则后果仍是功法修习准入判定式。

→ `systems/character-profile/deck/_index.md`。

## 理由

角色辨识度需要一根可复述的骨架，而灵根是既有的、玩家已能看见的五元分类——**复用它零成本**。

坚持「无规则后果」是承重的：一旦动词映射进入规则层，就等于从后门引入相生相克，与 `ADR-0123` 正面冲突，并且会诱导玩家去找一套并不存在的克制关系（与 `ADR-0226` 拒绝五行卡框色同源）。

## 备选方案

- **让五行映射产生规则后果（相生相克 / 属性克制）** — 否决：直接推翻 `ADR-0123`，且大幅抬高教学成本。
- **不给映射、逐门功法自由立项** — 否决：五个灵根池会失去分野，角色辨识度落空。

## 后果

- **五份灵根小池的功法立项按主动词归池。**
- **通用池承载跨行基础件**，其中必须包含基础拆解（→ `ADR-0231`）。
- 三条高光通道（→ `ADR-0228`）与五个动词部分重叠，这是有意的：高光通道说「爽点长什么样」，动词说「哪个灵根来演」。
