# ADR-0229 — 起始卡组不设统一底盘：15 张的形态完全由角色与其功法决定

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09b-combat-feel-identity.md

## 背景

起始卡组的规模已定（15 张 = 三门功法 × 5 张，→ `ADR-0185`）。剩下的问题是它的**形态**：五个角色是否共享一套底盘（例如「法术为底、阵法点缀」），再各自变体？

统一底盘的诱惑在于新手友好与制作顺序——先做一个标准模板，再改五份。

## 决策

**起始卡组不设统一底盘。** 每个角色起始 15 张的玩法、法术 / 阵法配比、展示哪条高光通道，**完全由该角色与其三门功法的核心决定**；不设统一的类型配比，也不限制起始卡组的复杂度与设计空间。

→ `systems/character-profile/deck/_index.md`。

## 理由

**类型配比本身就是角色辨识度的一部分**，统一底盘会把五个角色的首小时手感压成一个——这与「不设全局产削配比」（→ `ADR-0227`）同源。

「新手友好」不由底盘统一性承担，改由角色选择屏的**玩法简介**承担（→ `ADR-0234`）。

## 备选方案

- **法术为底盘、阵法点缀的统一起始形态** — 推翻（用户当场改判）：压平首小时手感，且会限制部分角色的核心玩法。
- **限制起始卡组的复杂度上界** — 否决：首批五角的复杂度收束是内容编排取向（同档从简），不由上界 / 配比这类结构性约束承担。

## 后果

- **starter deck 逐角色独立立形**，制作流程里没有「先做一个标准模板再变体」这一步。
- 首批五角的复杂度由内容编排收窄到同一档（五个都直白，谱系由后续系列的角色向上展开），但**不由任何配比或结构约束拉平**——压平是编排取向，不是规则。
- 与 `ADR-0232`（五行 → 主战斗动词）配套：角色的辨识度由灵根主动词 + 三门功法核心共同给出。
