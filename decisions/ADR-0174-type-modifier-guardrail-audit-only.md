# ADR-0174 — 类型修正的护栏咬归一化后的占比、不咬系数，且只审计不钳制

- **状态：** Accepted
- **日期：** 2026-09-06
- **来源：** handoffs/2026-09-06-event-type-mix-ratios.md · answer-logs/log-event-type-mix-ratios.md

## 背景

剧本可对五类事件的基础权重施加乘性类型修正（`ADR-0026`）。基础权重定值之后，随之而来的问题是：修正系数能有多大？没有护栏，一条剧本可以把某一类的实际占比推到接近 0 或接近 1，而那会让整章的节奏塌掉——但护栏本身该咬在哪一层、该不该在运行期拦下来，是两个独立的问题。

## 决策

**护栏咬在归一化后的占比，不咬系数本身。** 编排建议：系数 `[0.5, 2.0]`、**占比 `[5%, 55%]`**。

**落点 = `/audit-content` 汇总，只报告不阻断；不加运行期钳制。**

区间取值与逐条编排建议 → `systems/balance.md`、`systems/game-progression.md`。

## 理由

- **系数不是玩家能感知的量，占比才是**：同一个 `×2` 在不同基础权重上产生的实际占比天差地别，咬系数等于咬了一个与后果不成比例的量。
- **不加运行期钳制**：钳制会把「只改权重不改支撑集」变成「有时也改权重的大小关系」——一旦某格被钳到上界，剧本作者写下的相对意图就被静默改写了，而没有任何地方会报出这件事。
- **只报告不阻断**是本库对编排建议的标准落点（第 4 级纪律：零成本、零保证，如实标注）；这类区间本就是经验值，硬拦会在内容扩充期制造大量假阳性。

## 备选方案

- **在管线里对归一化后的占比做运行期钳制** — 否决：见上，会静默改写剧本的相对意图。
- **护栏咬系数区间并硬校验** — 否决：咬错了层，且同一个系数在不同基础权重下后果完全不同。

## 后果

- **越界的编排能上线**——这是有意的：护栏的职责是让越界**被看见**，不是让它不可能发生。
- **`/audit-content` 因此多一项汇总**（逐剧本报出各类型的归一化后占比）。
- 受约束的文档：`systems/balance.md` · `systems/game-progression.md` · `systems/services/plot-manager.md` · `decisions/ADR-0026-event-generation-weighting-pipeline.md` · `decisions/ADR-0013-discipline-enforceability-ladder.md`。
