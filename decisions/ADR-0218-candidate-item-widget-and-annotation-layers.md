# ADR-0218 — 统一「候选条目」构件六个位 + 三类标注层 + 长按说明通道；三条标注禁则

- **状态：** Accepted
- **日期：** 2026-09-08
- **来源：** handoffs/2026-09-08-portrait-option-list.md · answer-logs/log-portrait-option-list.md

## 背景

本库至今没有一套成文的「一批候选项怎么摆、怎么标、怎么解释」的通用语言，而「构筑面板与战后奖励面板同构」这句约束需要一个可独立成立的落点。

## 决策

**统一的「候选条目」构件 = 六个位**：类型 / 来源标识 · 标注带 · 视觉 · 名称 · 一行副文本 · 数值行。两条轴共用同一构件，只有外框比例不同。**六个位全部可空、缺位整格不渲染不留空占位；长文本永不截断成省略号；触控目标 = 整个条目。**

**标注层分三类，位置与优先序固定**：资源数值标注 → 数值行；状态 / 风险标注 → 标注带，静态常驻，**每条目至多 2 枚**；实例信息标注 → 数值行独立一行，同屏只标一次。

**三条禁则**：不加由已展示数字机械导出的符号 · 不显示隐藏的映射量 · 不做灰态表达「不划算」。

**统一说明通道三层深度全库共用**：恒常可见 → **长按**半屏 bottom sheet → 再叠一层。**绝不用悬停、绝不用「ⓘ」小图标。**

## 理由

`ux/screen-flow.md`：**不加由已展示的数字机械导出的符号**——同理不给「这一步会让你归零 / 跌破 10%」的卡片级致死标记：余量与成本两个数都已恒精确常驻，标记只是它们的机械导出物，**且它就是被否决的「大限将至」预警文案换一个视觉外壳**；它还会当场取消一条承重取向——「明知是死路仍然走」要求玩家**知情地**走进去。

说明通道的依据：**绝不用悬停**（无触控等价物）、**绝不用「ⓘ」小图标**（远小于最小触控目标的次级热区，会与整条目的点按热区争抢）。选长按而非点按：候选条目不可拖拽，按 `decisions/ADR-0085-gesture-split-tap-versus-longpress.md` 的分化判据用长按；且点按已被择一 / 选中占用，同一根手指上不能有两个点按语义。

## 备选方案

- **悬停** — 否决：无触控等价物。
- **「ⓘ」小图标** — 否决：热区争抢。
- **卡片级致死标记** — 否决：三条独立依据如上。

## 后果

- 约束所有决策面共用同一构件与标注位；事件选项卡的标注带**恒为空是结论不是遗漏**。
- 放弃了微缩排版与省略号；说明通道封死在长按一条路径上。
- 推论：**寿元告警只落角色状态条的 `❤` 位，不下沉到卡片层。**
