# ADR-0163 — 不设 ante 式章内绝对难度阶梯；随进度的数值分格轴只有两条

- **状态：** Accepted
- **日期：** 2026-09-06
- **来源：** handoffs/2026-09-06-blind-ante-scaling-curve.md · answer-logs/log-blind-ante-scaling-curve.md

## 背景

「blind / ante 缩放曲线」作为待答项在库里挂了很久，读起来像「连形态都没有设计」。它其实是 2026-07-24 文档重构（`blinds-antes.md` 并入 `game-progression.md`）时搬过来的**占位残留**：`blind` 侧此后已由 `combatTier` 三档完整承载，`ante` 侧则从未有过对应物。留着它会持续制造一个虚假的承重卡点——而它等不来任何输入。

同时，全库十一条随进度变化的曲线各自成文、从无一份总表，也就没人能回答「新加一个缩放旋钮，该按什么分格」。

## 决策

**一、本作不设 Balatro ante 式的章内绝对难度阶梯，也没有逐关抬高的过关阈值。** 三个构成要件一个都不成立：胜负是双方道念的相对比较，**没有可被抬高的静态阈值**；难度缩放是相对量且自动跟随（`±2` 赋级带 + `baseMomentum` 跨度内生兑现「越往后越难」）；进程没有固定节律的循环单位（Finale 只在篇章边界出现一次）。

**二、一切随进度变化的数值，分格轴只有两条（承重纪律）：** `①` **全局等级序 1–22**（相对量、逐级，承载「谁比谁强」）与 `②` **篇章 ch1–ch3**（绝对量纲吸收，承载「数字量纲膨胀多少」）。新增任何缩放旋钮，其分格列必须是这两条之一；**需要第三条轴（章内进度 / 已走过的 location 数 / 已完成事件数一类）须先立 ADR。**

**三、`blind` 侧待答项整条撤销**——过关条件 / 出场条件 / 难度缩放 / 奖励四个问法均已由 `combatTier` 与既有机制承载；正文里把 `blind` 当本作实体谈的位置全部改写为 `combatTier`，**注释与对位括注（说明借鉴来源）保留不动**。

十一条既有曲线登记表与两条轴的逐条归属 → `systems/game-progression.md`「难度与数值缩放的分格轴」。

## 理由

- **再叠一条随进度递增的绝对阶梯 = 在唯一可见的难度刻度（等级）之外开一条不可见的强度轴**，且任何「按进度加压」的实现都必须产出带外 `diff`，**直接撞 `±2` 硬规则**。
- **章内推进感已有两条既有机制承载**：等级成长（`baseMomentum` 上升 + 经验条常驻）与「越阶只出现在境界末两级」。
- **十一条曲线逐条都能归入两条轴之一、无例外**——这是分格轴纪律不是臆造的证据。
- 「篇章」已是量纲吸收的分格单位、已有名字与权威，**起别名只会同页两义**（与 `Tier` / `RarityTier` 不复用、`EnemyLevelRange` 不叫 `LevelBand` 是同一条纪律）。

## 备选方案

- **保留待答、等内容阶段再答** — 否决：它不是取值缺口，等不来输入，反而持续制造虚假的承重卡点。
- **`ante` 作篇章的别名** — 否决：同页两义。
- **登记表放 `balance.md`** — 否决：表回答的是进程侧问题，维持「进程侧归 `game-progression`、数值归 `balance`」的既有分工。
- **轻量的「按进度递增」阶梯** — 否决（用户裁决确认）：唯一不撞硬规则的形态也会引入第三条分格轴，并与越阶规则重复施压。

## 后果

- **第三条分格轴从此需要一次 ADR 才能引入。** 若实测发现「章中段太平」，补救限定为调既有曲线（`BatchSizeWeights` / 赋级权重的剧本乘性调制 / `eventCountLimit` 序列）——**关掉「补一条轻量阶梯」这条快速手段正是本条要的约束力。**
- **ch2 / ch3 中段的节奏缺口**（每 12–14 个事件才升一级）只由经验进度条补一半，维持现状——已知代价。
- **纪律的落点是设计评审（第 4 级：零成本、零保证，如实标注）**，`/audit-content` 无从检查、不进任何自动校验。
- **登记表只写指路与状态、不复制数字**——取值权威留在各自文档，表本身不成为第二数值源。
- 受约束的文档：`systems/game-progression.md` · `systems/balance.md` · `systems/_index.md` · `.claude/knowledge/systems/_index.md` 与 `.claude/knowledge/dictionary.md` 的 ante / blind 摘要随之失真，归 `/sync-knowledge` 对账。
