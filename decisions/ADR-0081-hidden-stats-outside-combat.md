# ADR-0081 — 隐藏属性不是战斗内资源：战斗层既不读也不写它，全部交互发生在事件层

- **状态：** Accepted
- **日期：** 2026-08-23
- **来源：** handoffs/2026-08-23g-hidden-stat-combat-boundary-event-backdrop-and-itemized-rewards.md

## 背景

隐藏属性（道心 / 煞气 / 寿元）是叙事与剧本调制的输入。一个自然的延伸是让它们也参与战斗——道心高则某些牌更强、煞气高则伤害加成。这会让隐藏属性成为一条贯穿全局的资源线。

## 决策

**战斗层不读写隐藏属性（承重边界 · 权威）。** 隐藏属性**不作为战斗内的资源或结算输入**；**隐藏属性与战斗的全部交互发生在事件层**——调制通道 / 结算输入通道 / `eventEnd` 推拉三条。

权威落 **`systems/services/plot-manager.md`**，不落 `systems/scoring.md`。

## 理由

隐藏属性进入战斗会让战斗数值多一条**玩家不可直读**的输入（它们是隐藏的，只以档位呈现）。而战斗已经有道念、mana、`lifeTotal` 三条可读资源，第四条不可读的输入会让局面无法推演。

权威落点必须是 `plot-manager.md`：`scoring.md` **零处提及隐藏属性**，把边界写在那里等于制造第二权威——一份讲计分的文档突然规定隐藏属性的边界，下一个改计分的人不会想到去读它。

## 备选方案

- **措辞写成「隐藏属性与战斗资源无直接耦合 / 不设直接读写通道」** — 否决：按字面会连既有三条通道一并否掉，与 `plot-manager.md`「输入侧全开」直接相抵。
- **权威落 `systems/scoring.md`** — 否决：该文件零处提及隐藏属性，会制造第二权威。

## 后果

- 两处**不构成反例**且已明写：`lifeSpanCost`（事件层的成本）与「按道念差扣 `lifeTotal`」（战斗结果写事件层）。
- 剧本对战斗的影响只能走 `EncounterTighten` 五格（→ `ADR-0077`），不能走隐藏属性。
- 战斗内容设计因此不必考虑隐藏属性的当前值。
