# ADR-0230 — 极限精简是被支持的高阶构筑路线：首批就放疲劳协同牌

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09b-combat-feel-identity.md

## 背景

抽牌堆不重洗、抽空即疲劳（→ `ADR-0052`），且卡组规模两侧都不设硬限。这留下一个可能：把卡组精简到疲劳线以下，用疲劳减免换取抽牌的确定性。

它到底是被支持的构筑路线，还是疲劳应当纯粹作为惩罚存在——这决定首批卡牌清单要不要预留协同位，也决定 `RemoveLooseCard` 的供给该按什么校准。

## 决策

**极限精简是被支持的高阶构筑路线。** 首批就放少量「疲劳减免 / 空堆收益」牌，使这条路线成为**可发现的隐藏流派**。

载体是既有的 `StaticModifierData { What = FatigueAmount }`，可将疲劳削至 0——**零新增机制**。

→ `systems/character-profile/deck/_index.md`；机制侧 → `systems/character-profile/deck/common-properties.md`。

## 理由

**接口已就位、零结构成本**：疲劳不是效果原语，因此「削减疲劳量」这类静止式修正天然可写（→ `ADR-0115`）。

它是「deck 即 build」这条支柱的深度兑现——卡组规模本身成为可操作的旋钮，而不只是一个被动累积的数字。

它与敌人轻量档（10–12 张样本卡组）的镜像设计呼应：敌我同构，玩家能做的事敌人也能做。

## 备选方案

- **疲劳纯惩罚、不放协同牌** — 否决：白白关掉一条零成本的深度路线，且与不设卡组规模硬限的既定形态相抵。

## 后果

- 首批卡牌清单**预留疲劳协同位**。
- `RemoveLooseCard` 的供给（闭关精简一类）按「**这条路线可行**」校准，不得少到让精简流不成立。
- 与「业障在 ch1 低频但沉重」（→ `ADR-0235`）之间的张力是**有意设计**：想洗掉业障就要付真实代价。
