# ADR-0211 — 颜色管「哪一类」、形状管「同一类」：类型角标脱色后仍须两两可辨

- **状态：** Accepted
- **日期：** 2026-09-08
- **来源：** handoffs/2026-09-08-combat-ui-elements.md · answer-logs/log-combat-ui-elements.md

## 背景

full art 下，卡框色与类型角标是卡面上仅有的两个非 `manaCost` 呈现元素（`decisions/ADR-0083-full-art-card-face.md`），其权重与可辨性随之升格，但两者的分工从未写死。

## 决策

**颜色管「哪一类」、形状管「同一类」**：**类型角标必须是形状化图标，脱色后仍两两可辨**。

**卡框色 = 外缘细描边 + 一条较厚色带，不整框着色。**仍做一套五色，**但缩略可辨性只按四类校准**（战斗内 `Power` 一律以技能条目呈现）。

**`Affliction` 的角标须最醒目。**色相三约束 = 缩略尺寸两两可辨 · 灰度化后两两可辨 · 不与三套状态视觉相撞。

## 理由

`ux/combat-ux.md`：**两个元素并存的全部意义就是冗余编码**；若角标只是一块与卡框同色的色块，两者表达同一维度即是浪费。小尺寸下的颜色分辨率不足与色觉障碍是移动端的无障碍底线。

`Affliction` 最醒目的依据：它是唯一「打出无任何正面效果」的类型，**在手牌区认错它的代价高于其余四类**。

## 备选方案

- **角标只是与卡框同色的色块** — 否决：两元素表达同一维度即是浪费。
- **整框着色** — 否决：吃插画面积，而缩略可辨是认牌的唯一通道。

## 后果

- 约束角标必须脱色可辨、色相必须灰度化可辨。
- 放弃了整框着色的视觉冲击。
- 五色齐做但只按四类校准。
- 色相与字形的具体取值待美术基调落定，约束已可机械核对；卡框色与类型角标属 UI 元件类目、与插画分开生成（`art/visuals/art-direction.md`）。
