# ADR-0177 — 轮回内不提供任何「距 Finale / 距圆满」的前瞻读数，三章一律不显示

- **状态：** Accepted
- **日期：** 2026-09-06
- **来源：** handoffs/2026-09-06-finale-trigger-and-foresight-declined.md · answer-logs/log-finale-distance-foresight.md

## 背景

「中长期规划感的来源」是元进程侧挂着的一条待答项：玩家在篇章中段没有任何量能回答「我还差多远到 Finale」。它看起来是个明显的缺口——直到把补法逐条摊开，才发现每一种都要么给出一个会错的数，要么要暴露本该隐藏的机制。

Finale 的触发条件本身是清楚的：`level == 该境界末级`（全局序 13 / 17 / 21），判定式与抬升条件的权威在 `systems/services/future-event-service.md`，进程侧只钉判定式并回链、不复述抬升条件表。

## 决策

**轮回内不提供任何「还有几步到 Finale / 距圆满还差几级」的读数——三章一律不显示。** 这是**被接受的取向，不是待补的缺口**。

**篇章进度条（`x / N` 形态）另有一条独立的否决理由：分母在轮回进行中不存在**，且**事件数并非 Finale 的闸门**。

**也不给「预计还需约 M 个事件」的估算读数**——**给一个不会错的数，不给一个会错的估。**

## 理由

- **`x / N` 的分母不存在**：本章还会出现多少事件取决于玩家的选择与 `eventCountLimit` 序列，运行中没有任何时刻能算出它；而即使算出来，事件数也不是 Finale 的触发条件——等级才是。
- **估算读数要暴露隐藏经验档位映射**，且它是一个**会被两次失败打脸**的期望值——`ADR-0175` 刚把「两次典型失败」定为常态容错，这个估算平均每轮回会错两次。
- **推进感已有承载**：等级成长与经验条常驻（`ADR-0163` 的同一条理由）。缺的是「还差多远」，而这个量在本作的机制下**没有诚实的答案**。

## 备选方案

- **补一格「距圆满 N 级」读数**（草稿推荐） — 否决（用户裁决）：在明知代价（节奏缺口只补一半 · 失败螺旋只能事后发觉 · 该角长期无第二个量能回答）的前提下否决。
- **篇章进度条 `x / N`** — 否决：分母运行中不存在，且事件数不是闸门。
- **「预计还需约 M 个事件」估算** — 否决：要暴露隐藏经验档位映射，且是会被两次失败打脸的期望值。

## 后果

- **失败螺旋只能事后发觉**——玩家在陷入螺旋的当下拿不到任何前瞻信号，这是被明确接受的代价。
- **「中长期规划感」这条待答项就此关闭**，不再作为待补缺口登记；它现在是一条已裁决的取向。
- **Finale 触发条件在进程侧只写判定式 + 回链**，抬升条件与置位口径的单一权威留在 `systems/services/future-event-service.md`。
- 受约束的文档：`systems/game-progression.md` · `systems/services/future-event-service.md`（权威侧零改动）· `ux/screen-flow.md`（零改动）。
