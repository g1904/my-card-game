# ADR-0236 — 寿元跌破低位播一次性低调提示音：不循环、不常驻、不震动

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09c-audio-direction-nine-axes.md · answer-logs/log-audio-direction.md

## 背景

寿元余量低于本章可用预算 10% 时转红字，那是**纯视觉强调**，且明确不做「大限将至」一类的预警文案。剩下的问题挂了很久：这一刻要不要伴随音效或震动。

同一屏上还有一个反例：抽牌堆见底预警**明确不加音效**（→ `ADR-0214`）。两者若不给判据，日后必然被读成互相矛盾。

## 决策

**跌破低位阈值那一刻播一次性低调提示音**（短促低沉，如一声闷钟）：**不循环、不常驻、不震动**，也不因余量持续走低而重复。

**判据 = 作用域：寿元是跨事件的全局命线，疲劳是回合内的局部读数。** 前者值得一次听觉确认，后者不值得。

**红字仍是纯视觉强调**，提示音是与它并列的**一次听觉确认**；**不引入任何预警文案**（该禁令原样保留）。

形态 → `ux/screen-flow.md`；音色与材质 → `art/soundtracks/audio-direction.md`；音频侧登记 → `art/soundtracks/_index.md`。

## 理由

寿元是角色**唯一的命线**，被削到低位是全局最重的一次状态变化——它是全作里少数几个「值得打断玩家注意力一次」的时刻。

**一次性不骚扰**，与 grimdark 听觉基调的克制一致（爆发只留给 Finale）；循环或常驻会把一条命线读成一个持续的噪声源。

不震动是因为震动没有强弱分级，用在这里等于把它烧掉，日后再无更重的时刻可用。

**静音容错纪律不放松**：这条听觉信息有完整的视觉等价物（红字 + 常驻精确余量），因此关掉声音不构成信息缺失。

## 备选方案

- **不加任何音效**（与疲劳见底预警同款处置） — 否决：作用域不同，全局命线值得一次确认。
- **循环 / 常驻的告警音** — 否决：骚扰，且与克制的听觉基调相抵。
- **加震动** — 否决：震动无分级，用在此处即耗尽该通道。
- **补一句预警文案** — 否决：余量既已明文常驻且精确，预警文案没有存在理由。

## 后果

- `ux/screen-flow.md` 与 `art/soundtracks/_index.md` 上的「寿元跌破低位是否伴随音效 / 震动」待答项**就此关闭**。
- 音效条目本身归 BGM 之后的音效类目 guide（→ `art/soundtracks/guides/_index.md`），本条只定行为形态，不定音色取值。
- 与 `ADR-0214`（疲劳见底预警只给一档纯静态）**并存且有判据**，两条不得被互相援引推翻。
