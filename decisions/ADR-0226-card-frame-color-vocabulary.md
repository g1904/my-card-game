# ADR-0226 — 五类卡框色取仙侠意象色，明确不套五行；意象服从可辨性

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09-art-direction-nine-axes.md · answer-logs/log-art-direction.md

## 背景

卡牌类型五分已定，且颜色被指定为「管哪一类」的通道（→ `ADR-0211`）。剩下的问题是这五个色从哪里取。

项目里恰好存在一套现成的五元色系——五行。直接借用是最省力的写法，但本作的五行只在灵根侧有语义，且**灵根唯一的规则后果是功法修习准入**，五行之间没有任何相生相克。

## 决策

**五类卡框色的色彩语汇 = 仙侠意象色，不套五行。** 每类从**自身意象**取色（业障取瘴紫黑、阵法取符箓金一类方向）。

**意象服从可辨性**：色相选择以三条既有机械约束为优先——缩略尺寸下两两可辨 · 灰度化后仍两两可辨 · 不与三套状态视觉相撞。

**本条只锁语汇，不代取值**；具体色值归 guide 编写期定稿。语汇本体 → `art/visuals/art-direction.md`「色彩」；取值格照旧留在 `ux/combat-ux.md` 的待决区。

## 理由

五类卡牌与五行**并无语义对应**，硬套会诱导玩家去找一套并不存在的相克关系——世界观表达换来的是机制上的不诚实。

且五行色一旦被卡框占用，日后若真要在灵根 / 属性侧引入五行色，两处会当场撞车。

## 备选方案

- **借五行色** — 否决：暗示不存在的相克关系，并占用灵根侧未来可能需要的色语汇。
- **纯功能色（色轮等距取五色）** — 否决：浪费一层免费的世界观表达，而三条机械约束用意象色同样能满足。

## 后果

- 色相自由度被三条机械约束框住：**当意象色与可辨性冲突时，改的是意象**。
- `ux/combat-ux.md` 的「五类卡框色具体色相」待决项**只剩取值**，语汇前提已定，该条不再是形态缺口。
- 与 `ADR-0211`（颜色管「哪一类」、形状管「同一类」）配套：本条定色从哪来，`ADR-0211` 定色与形状各管什么。
