# ADR-0227 — 战斗基调 = 产道念为主旋律、削减与拆解为反制；不设任何全局配比口径

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09b-combat-feel-identity.md

## 背景

量纲与形状已经定完（兑换率 `momentumPerMana = 1`、摆幅、费用曲线、牌流、起始 15 张、`MaxTier = 5`），但**内容该长成什么样**仍是空的：一场战斗里，玩家主要在堆自己的分，还是主要在拆对方的分？

这一层不定，首批卡牌清单与敌人兜底 AI 的权重取向都没有依据；而定得太死，五个角色的手感会被压成一个。

## 决策

**全局基调 = 产道念为主旋律，削减与拆解为反制手段。**

**不设任何全局产削配比口径**：内容侧不做全局产削比对账，也不为任一角色或功法规定产削比例——**允许整门功法完全偏离基调**（削拆向的功法、金系角色皆是正当形态）。

基调本体与它的编排后果 → `systems/character-profile/deck/_index.md`。

## 理由

- **堆自己的分好懂**，符合「直觉化」这条支柱；以拆解为主旋律的战斗要求玩家先读懂对方，教学成本高一个量级。
- 道念的**下限 0 截断**使削减在炼气早期（`baseMomentum` 仅 1–3）天然贬值、随篇章自然升值——反制的分量本就由量纲自动调节，再钉一个全局比例是重复施压。
- **不钉数字是有意的**：产削配比与类型配比都是角色辨识度的载体，一个全局比例会把五个角色的手感压成一个。

## 备选方案

- **给一个全局产削配比（如 7 : 3）** — 否决（用户两度明确推翻）：压平角色辨识度，且该数字无法被任何机制校验。
- **以削拆为主旋律** — 否决：与直觉化支柱相抵，早期还因下限 0 截断而近乎无效。

## 后果

- **内容侧不做全局产削比对账**——`/audit-content` 不设这一项。
- 敌人兜底 AI 的权重取向依据挂**方向**而非数字（→ `systems/enemies/_index.md`）。
- 「反制要有稳定供给」这条约束因此必须另立，不能靠配比隐含地保证。
