# ADR-0209 — 0 值处置的判据 = 它是不是一个入口：入口置灰保留，指示淡出

- **状态：** Accepted
- **日期：** 2026-09-08
- **来源：** handoffs/2026-09-08-combat-ui-elements.md · answer-logs/log-combat-ui-elements.md

## 背景

「计数为 0 时是隐藏还是保留」此前在两处各自随手处置；而己方埋伏若在 0 值 / 溢出时折叠，会与「启动式异能宿主 = 战场条目自身」直接冲突。

## 决策

**随身角标**（胶囊形容器 = 道具图标 + 数字徽章）在可用件数为 0 时**置灰保留、不隐藏**。

**对手侧埋伏计数**在计数为 0 时**整格淡出、容器尺寸不变**。

**己方埋伏** = 战场条目的面朝下变体，与正面阵法同尺寸同槽位、**逐条渲染**；溢出退让为带内横滚，**绝不退让为折叠**。

**两侧 0 值处置不同的判据 = 它是不是一个入口。**

## 理由

`ux/combat-ux.md`：随身角标是入口，必须可点、必须能给说明，故置灰保留；敌方埋伏计数是纯指示，无处可点，淡出即答案。**两者都不改变布局，这一点没有分化。**

隐藏被否的依据：会让玩家以为功能消失且无处解释，也会让己方战场带的可用宽度在战斗中途变化。

不折叠的依据：**折叠后没有可寻址的战场条目宿主，启动入口即失去落点**（`decisions/ADR-0149-enchantment-activated-ability-host.md`）。

## 备选方案

- 己方埋伏「折叠 + 另造一层展开列表」 — 否决：撞「零新增常驻部件」。

## 后果

- 约束两侧布局在 0 值时尺寸不变；放弃了 0 值时的屏幕回收。
- 承 `decisions/ADR-0142-grayed-state-is-visual-only.md` 的灰态纪律：置灰的随身角标继续接收触控并给说明。
