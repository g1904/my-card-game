# ADR-0225 — art guide 粒度 = 一类目一份 guide + 逐条目变量段；例外升格须在类目 guide 登记指针

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09-art-direction-nine-axes.md · answer-logs/log-art-direction.md

## 背景

资产是**分次生成**的：一批卡牌插画不会一次跑完，敌人立绘会随内容扩充陆续补。分次生成的最大现实风险是**风格漂移**——同一类目的前后两批读起来像两个项目。

`art/visuals/_index.md` 因此挂着一条待决项：guide 写到多细。逐条目一份 guide 表达力最强但没有任何收敛手段；一份总 guide 打天下则写不出条目之间的差异。

## 决策

**一个资产类目一份 guide**，承载该类目的**公共段**（风格、构图规范、参考素材、prompt 骨架、参数）；**逐条目只填变量段**（主体、构图差异、情绪）。

**少数需要特殊表达的条目**（Finale 敌人、关键角色一类）**可例外升格为独立 guide**，但**必须在所属类目 guide 中登记指针**。

模板形态（公共段 / 条目变量段 / 例外升格登记三块）→ `art/visuals/guides/_TEMPLATE.md`；约定本体 → `art/visuals/_index.md`「承重约定 · guide 粒度」。

## 理由

**稳定性优先于表达力**：共享的公共段是分次生成下唯一的风格收敛手段，而表达力的缺口可以由一条显式通道补回——反过来则不成立。

登记指针是这条例外通道的承重部分：**不登记的升格会让两份 guide 各自漂移，而本库没有任何机制能发现**（与 `ADR-0005` 的副本判据同源）。

## 备选方案

- **逐条目一份 guide** — 否决：无收敛手段，风格漂移必然发生。
- **一份总 guide 覆盖全部类目** — 否决：类目之间的构图规范与参数本就不同，公共段会被稀释成空话。
- **允许例外升格但不要求登记** — 否决：制造无人发现的第二权威。

## 后果

- `guides/_TEMPLATE.md` 按「公共段 + 条目变量段」两块组织，并留出例外升格的登记位。
- 逐条目的资产需求收敛为**三个变量**（主体 / 构图 / 情绪），条目层不重复写风格与参数。
- 类目 guide 的编写顺序另有约定（音频侧 BGM 在前、音效在后 → `art/soundtracks/_index.md`），本条只定粒度不定顺序。
