# ADR-0257 — 通用 / 专属功法配比 = 按稀有度分层的梯度，无硬限制

- **状态：** Accepted
- **日期：** 2026-09-10
- **来源：** handoffs/2026-09-10-character-series-identity-and-monetization.md · answer-logs/log-character-technique-identity.md

## 背景

灵根修习准入是硬收缩：每个角色的可修池 = 「自己属性的功法」+「无属性要求的通用功法」。通用功法是压低首批内容量的主要手段（否则五个不相交的池各要独立铺够），但**它占多大比例**此前无口径——比例定高则五个角色玩起来一个样，定低则首批内容量乘以五。

## 决策

**配比取梯度而非一刀切，且不设任何硬限制。** 每个稀有度档都有通用与带灵根的功法：**稀有度越低通用比例越高，且每种灵根都有低稀有度功法；稀有度越高通用仍存在但比例较少、大多带灵根要求。**

- build-around 的高稀有度功法**一律带属性**；允许存在的高稀有度通用功法**限于无条件直给型**（大额直接产念、稳定底盘的高级版一类）。
- 配比须为未来的宽池（多灵根）角色预留编排空间。
- **这是编排口径，不是字段约束**；逐档比例数值归内容阶段随 ch1 starter deck 打磨定。
- `/audit-content` 按稀有度档统计通用 / 专属占比、按角色统计可修池构成作核对面，**只报告不阻断**。

→ `systems/character-profile/deck/_index.md`「内容编排口径」。

## 理由

`systems/character-profile/deck/_index.md`：**辨识度因此是分层的**——低稀有度底盘大量共享（省内容、直白），稀有度越高专属比例越高，记忆点全在亮点层。一刀切的全池比例与「底盘共享、亮点分化」这条分层本性不合，且会把各档的编排自由一并锁死。

## 备选方案

- **全池目标带**（一刀切比例） — 否决：与分层本性不合，锁死各档编排自由。
- **专属优先** — 否决：首批内容量乘以五。
- **共享优先** — 否决：五个角色玩起来一个样，辨识轴归零。

## 后果

- 约束 `deck/_index.md` 的功法池形状写法（五份小池 + 一份共享池）与 `/audit-content` 的核对面形态。
- 逐档比例数值不在本条内——它待 ch1 starter deck 打磨，留在待答清单。
- 与 `decisions/ADR-0229-no-shared-starter-deck-baseline.md`（起始卡组不设统一底盘）同向：共享落在**池**的底盘层，不落在**起始卡组**的形态层。
