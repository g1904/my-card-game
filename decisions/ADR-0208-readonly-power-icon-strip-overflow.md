# ADR-0208 — 只读层 = 单行图标条 + `+N` 溢出格，不折叠不滚动，`K ≥ 3`

- **状态：** Accepted
- **日期：** 2026-09-08
- **来源：** handoffs/2026-09-08-combat-ui-elements.md · handoffs/2026-09-08-combat-portrait-layout.md · answer-logs/log-combat-ui-elements.md

## 背景

神通不设持有数量硬上限 ⇒ 只读层的条目数无上限，形状必须能容纳任意 N 条。而两份姊妹草稿对这个形状给出了互相矛盾的两案，必须裁一个跨稿统一口径。

## 决策

**只读层（神通 / 法则）= 单行图标条 + `+N` 溢出聚合格；不折叠为角标、不做任何滚动。**

`K = floor(可用宽度 ÷ (最小触控目标 + 间距))`，**硬下界 `K ≥ 3`**，初值 5。**溢出格不得吞掉启动可供性**——折进去的条目中若有一条可启动，`+N` 格自身即带强调态。

固定序 = 神通在前、法则在后，同段按入场顺序，**不按稀有度**。宽度不足时整条上移为战场带上沿的「己方资源条」，**不得移出战场区**。

## 理由

`ux/combat-ux.md`：**不折叠为角标**——随身是可操作层，角标点开是操作入口；只读层的全部价值是**常驻可读**（`Power` 开局入场、整场不变），藏进角标等于逼玩家每回合去查。

**不滚动**——横滑已被随身抽屉与事件选项占为「浏览候选」的语义，且图标条贴战场带边缘，横滑与「拖出手牌区 = 打出」的起手在同一片区域争同一根手指；滚动条本身也给不出「还有几条没看到」的常驻表达。

**不得移出战场区**——`Power` 住在战场上，位置即语义。

## 备选方案

- **折叠为角标** — 否决：只读层的价值是常驻可读。
- **横向滚动** — 否决：语义已被占用 + 与拖拽争同一根手指。
- **垂直窄带 + 纵向滚动**（姊妹草稿的另一案）— 作废：本条即跨稿统一裁决。

## 后果

- 约束 `K` 为派生量，不得写死。
- 放弃了容量无上限的常驻可读性，超出部分沉入半屏 sheet。
- 退让位限定在战场区内。
- 是 `decisions/ADR-0099-combat-holdings-two-tiers.md`「只读层」那一半的形状补齐，不推翻其分层原则。
