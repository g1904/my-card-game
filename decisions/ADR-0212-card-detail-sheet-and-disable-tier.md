# ADR-0212 — 卡牌详情页 = bottom sheet 上界屏高 60%，禁用档与战报展开态同档

- **状态：** Accepted
- **日期：** 2026-09-08
- **来源：** handoffs/2026-09-08-combat-ui-elements.md · answer-logs/log-combat-ui-elements.md

## 背景

full art 把一切文字后置到详情页，详情页的内容清单与排布因此成为承重项；而它的禁用规格与另外两类面板（随身抽屉 / `Power` 弹层、战报展开态）是否一致，此前未定。

## 决策

**卡牌详情页 = bottom sheet，内容自适应、上界屏高 60%、超出页内滚动；不分区、不分页、不加 tab。**内容七项自上而下，**缺项整行不渲染**；战斗内**不显示 `Rarity`**。关键字仍走长按二级展开，宿主换成详情页。

**禁用档与战报展开态同档**：敌人回合 / 结算中**可开**，选目标态下入口天然不存在。三行对照表见 `ux/combat-ux.md`。

## 理由

`ux/combat-ux.md`：一张牌的详情项数只有 5–7 项，不值得分类；tab 在触控上多一次点击，而滚动是移动端母语行为。

禁用档的判据仍是「争屏幕还是争语义」：**手牌详情页纯只读、不可能改变局面 ⇒ 不争语义；它是半屏面板 ⇒ 争屏幕。故敌人回合 / 结算中可开。**

## 备选方案

- **分区 / 分页 / 加 tab** — 否决：理由如上。
- **与随身抽屉同规格禁用** — 否决：纯只读不争语义。

## 后果

- 约束了「纯只读不是豁免理由」这条既有措辞的适用边界：详情页只争屏幕，故可开。
- 放弃了敌人回合 / 结算中对战场阵法规则文字的查阅（那属另一档，代价已明写接受）。
- 是 `decisions/ADR-0085-gesture-split-tap-versus-longpress.md`「点按手牌 = 升起详情页」的内容与禁用档补齐。
