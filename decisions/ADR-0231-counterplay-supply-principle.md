# ADR-0231 — 反制的供给原则：削与拆并重，拆解不得稀有化

- **状态：** Accepted
- **日期：** 2026-09-09
- **来源：** handoffs/2026-09-09b-combat-feel-identity.md

## 背景

阵法滚雪球被定为首批三条高光通道之一（→ `ADR-0228`）。滚雪球成立的前提是**雪球可被拆**：若拆解类条目稀有，先铺者必胜、敌方雪球无解，滚雪球会从「高光」退化为「唯一解」。

而全局产削配比已明确不钉数字（→ `ADR-0227`），反制的分量因此不再由任何比例隐含保证，必须单独立一条供给原则。

## 决策

**削与拆并重，拆解不得稀有化。** 这是**全局供给原则、不钉比例**：「削对方道念」与「拆对方战场永久物」两类反制，在全局内容池里都须有**稳定供给**。

拆解沿用既有原语 `RemoveEntryEffect`，**不为本条新增任何机制**。

→ `systems/character-profile/deck/_index.md`。

## 理由

滚雪球作主高光的前提是雪球可被拆。**拆解一旦稀有，先铺者必胜**——这不是难度问题，是策略空间坍缩。

不钉比例而给原则，是因为比例本身无法被机械校验，而「大于 0 且非孤例」可以。

## 备选方案

- **给拆解一个全局占比数字** — 否决：与「不设全局配比口径」相抵，且该数字不可校验。
- **让拆解稀有以突出滚雪球** — 否决：滚雪球会退化为唯一解。

## 后果

- **`/audit-content` 侧可核「拆解类条目 > 0 且非孤例」**——这是本条唯一的机械落点。
- **金系（削拆动词的主承载，→ `ADR-0232`）之外也要有跨灵根可得的基础拆解供给**，落在通用池；否则非金系角色对敌方雪球零解。
