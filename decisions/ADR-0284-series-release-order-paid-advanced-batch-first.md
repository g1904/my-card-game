# ADR-0284 — 系列推出次序首次定序：先单灵根五角进阶付费批，双灵根免费批在后

- **状态：** Accepted
- **日期：** 2026-09-12
- **来源：** handoffs/2026-09-12-series-packaging-and-narrative.md · answer-logs/log-monetization-packaging-and-narrative.md

## 背景

首批五角之后有两条已知的扩张路线：单灵根进阶批与双灵根批。`decisions/ADR-0258-multi-affinity-free-track-and-pool-split.md` 已定双灵根走免费轨道，`decisions/ADR-0259-first-batch-flattened-complexity.md` 已定复杂度谱系由后续系列展开 —— 但**两批谁先出**从未定过。次序直接决定首发后第一次大更新是付费内容还是免费内容。

## 决策

**推出次序：先付费进阶批、双灵根免费批在后。这是全库第一次给后续角色系列定序。**

**第一个付费系列 = 单灵根五角进阶批**：5 个角色、五行对称、**仍是单灵根**，但**复杂度高于首批**；定价锚 = 付 4 个单解之价。它落在「首批压平复杂度、由后续系列抬升」那一格，且**不触碰双灵根机制**。

**双灵根批仍走免费轨道**，只是排在付费进阶批之后。

**「复杂度抬升」不得表达为强度抬升** —— 进阶批卖的是更繁的运营与更深的组合空间，不是更高的胜率。

## 理由

`systems/monetization.md`：首发后第一次大更新是付费内容，观感风险如实记下，由两条既有纪律承接 —— **「严格横向不卖强度」**（`decisions/ADR-0255-paid-character-series-track.md`）与**「未拥有角色完全不出现在角色选择屏」**（`decisions/ADR-0277-paid-series-surface-enumeration.md`）。后者尤其关键：付费面不可见，第一次更新就不会表现为一次推销。

付费批不触碰双灵根：双灵根的双机制区分（复合功法 + 数量上限）**尚未实测**，让它先面对付费玩家是把未验证的机制押在最不容错的人群上。

## 备选方案

- **双灵根十角改做付费首批** — 否决：明确推翻既定的免费轨道，且让未经实测的双机制区分先面对付费玩家。
- **双灵根免费批在前、付费批在后** — 否决：用户裁定次序为付费在前；免费批先出会让进阶批的复杂度卖点被双灵根的新机制盖过。
- **两批同时出** — 否决：首发后第一次更新同时引入付费轨道与新机制，两处风险叠加且无法归因。

## 后果

- 复杂度谱系的展开顺序自此确定：首批（压平）→ 单灵根进阶付费批 → 双灵根免费批。
- **仍未定：** 双灵根免费批的**具体推出时点**（只定了排在第一个付费系列之后，未定隔几个版本）· 进阶批「复杂度更高」的**具体表达**（更繁的运营？更多条件判断？更长连锁？属内容与数值阶段）。
- `vision/scope.md` 记下这是**唯一已定的排期口径**，其余排期一概未定。
