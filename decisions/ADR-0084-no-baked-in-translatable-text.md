# ADR-0084 — 插画内不得烧入承载可翻译语义的文字；装饰性符文 / 书法 / 印章 / 碑文豁免

- **状态：** Accepted
- **日期：** 2026-08-25
- **来源：** handoffs/2026-08-25-combat-presentation-and-action-result.md

## 背景

生成出的插画里若含文字，那份文字就绕过了唯一的语言开关——切到英文时它仍是中文，且改一个字要重新生成整张图。

但本作是修仙题材：符箓、匾额、碑文、书法笔触、印章都是核心美术语汇，有一张牌的主体就是符箓。一刀切「禁任何字符」会砍掉这一整块。

## 决策

**插画内不得烧入承载可翻译语义的文字。** 卡名、规则文字、UI 文案、可读为语句的招牌与题字，一律不入图。

**装饰性符文纹样 / 书法笔触 / 印章 / 匾额 / 残缺碑文豁免**——判据是它是否**承载可翻译的语义**，不是它是否是字符。

**适用于全部七个资产类目**，不止卡面。

→ `art/visuals/art-direction.md`（权威）；回链 → `art/visuals/_index.md`、`art/_index.md`。

## 理由

约束的真正目标是**语言开关的完整性**：一句可读为语句的题字在英文 locale 下留在中文，玩家看到的是半英半中的界面。而符箓纹样在任何语言下都读作「符箓」，它不承载可翻译的语义，因此不构成问题。

适用面从卡面**提升**为全部七类目，是因为背景板、事件插图、UI 素材同样会被生成，同样会烧入文字。

## 备选方案

- **禁任何字符** — 否决 / 收窄：按字面会砍掉符箓、匾额、碑文、书法笔触、印章等中式美术核心语汇，而本作有以符箓为主体的牌；其理由只对**承载语义的文字**成立。

## 后果

- 这条约束进入全部七个类目的 art guide 模板，是 prompt 的固定段落。
- 需要文字的地方（卡名、规则）一律由 UI 层叠加，走翻译键（→ `ADR-0056`）。
- 审校时的判据是一句反问：「这段字换成英文会不会需要重画」——会 ⇒ 违规。
