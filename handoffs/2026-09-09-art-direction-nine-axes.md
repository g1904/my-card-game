## Intent（distilled）

**一句话：** 厚涂写实的中式卡牌插画、水墨氛围点缀；冷光暗调的 grimdark 修仙世界，修行的灵光是唯一的暖色；人物写实英气、不浪漫不卖萌；压抑靠氛围而非血腥；竖版构图、暗底之上主体高对比。

这一场把 `art/visuals/art-direction.md` 长期空着的 `> _..._` 占位段落一次填满，并同时关闭 `art/visuals/_index.md` 的两条待决项（UI 元件的制作路径、guide 的粒度）。九条裁决全部落在既有决策与 ADR 框定的选项空间内，**未推翻任何既有权威**。

### 三条独有特色（本方向区别于泛仙侠的地方）

- **「灵光是唯一的暖色」。** 冷光暗调的世界 + 修行灵光的局部暖 / 异色点缀，把 grimdark 基调与修仙题材焊在同一条视觉规则上。它同时给「主体焦点高对比」一个叙事理由，而不只是手机可读性的妥协。
- **仙侠意象色的五类卡框，不套五行。** 色彩语汇从各类卡牌自身的意象取色，拒绝借五行色暗示一套并不存在的相克关系——世界观表达与机制诚实兼得。
- **地域色相签名。** 换地域即换色感，与「一地域一张事件背景板」的既有结构天然对齐，让三章的攀登在视觉上有推移感，而不动条目跨章复用的既定形态。

### 逐轴定案

| 轴 | 定案 | 承重理由 |
|---|---|---|
| 1 绘画质感 | **厚涂写实为主，水墨作氛围点缀**（雾、尘、墨韵在氛围层，不是主体语言） | grimdark 的重量感要靠暗部细节与材质承载；厚涂主体边缘清晰，利于「缩略可辨」硬约束 |
| 2 残酷尺度 | **压抑由氛围承载**（色彩、光照、残垣、枯骨远景、荒芜、人物神态），**不画血腥特写与恐怖直给** | 「留给想象」比直给更沉；发行侧对血腥暴力的敏感会框定批量生成资产的返工风险 |
| 3 色彩策略 | **暗基调公共板 + 地域色相签名 + 主体焦点高对比**；全局色板**不随境界推移** | 与「一地域一张背景板」对齐；境界感已由「按条目叙事定位取沉」承担，色板绑章会与条目跨章复用（`EncounterScopes`）打架 |
| 4 人物美型度 | **写实英气**——写实、有英气与美感，不锐化美型不卖萌；风霜、疲惫、伤痕按叙事定位入画 | 站在「仙侠受众的审美期待」与「grimdark 不浪漫」之间的中位，与厚涂参照系同源 |
| 5 光照性格 | **冷光主调 + 灵光点缀**——阴天漫射 / 冷月光作主光源，法术 / 符箓 / 丹炉的灵光作局部暖 / 异色点缀 | 「冷世界里唯一的光来自修行」与核心幻想同构，并给焦点高对比一个叙事理由 |
| 6 卡框色语汇 | **仙侠意象色，不套五行**——每类从自身意象取色（业障取瘴紫黑、阵法取符箓金一类方向）；色相选择以三条机械约束为优先，**意象服从可辨性** | 五类卡牌与五行无语义对应，硬套会误导玩家寻找不存在的相克关系；未来若引入灵根 / 属性系统再用五行色会撞车 |
| 7 UI 材质隐喻 | **暗色扁平打底 + 古物细节点缀**（简牍纹、印泥、符纹描边落在边角） | 可读性与九宫格拉伸最友好、GL Compatibility 零压力；信息密度最高的战斗屏不被材质噪声干扰 |
| 8 UI 制作路径 | **混合路径**——扁平底子（面板 / 按钮底 / 状态变体）人工 / 矢量制作不进 AI 流水线；古物点缀素材（符纹、印泥、纹样）走 Midjourney 生成后裁切入 UI | 扁平底子本就是纯色块与描边，AI 无增益；点缀素材恰是 AI 低成本产出的甜区；九宫格与状态变体零风险 |
| 9 guide 粒度 | **类目 guide + 条目变量**——一个资产类目一份 guide，逐条目只填主体 / 构图 / 情绪变量；少数需特殊表达的条目（Finale 敌人、关键角色）可**例外升格**为独立 guide，并在类目 guide 中登记指针 | 分次生成的最大风险是风格漂移，稳定性优先；表达力缺口由显式的例外升格通道兜住 |

### 各轴被否决的方向（理由承重，避免日后重提）

- **轴 1：** 浓水墨 / 国画感——偏离两个既定参照锚点，AI 稳定性与暗部表现更难控。风格化混合——风格化的「轻」抵消 grimdark 的阴郁。
- **轴 2：** 上调尺度属发行期重估，**不预留口子**（各 guide 的禁用词直接包含 gore / 断肢 / 血腥特写）。
- **轴 3：** 「色板随境界推移」与「完全统一一套」均否决。
- **轴 4：** 「美型为底 + 残酷点缀」——脸上的「净」持续对冲 grimdark，易读成廉价仙侠。「40k 式粗粝」——对仙侠受众第一眼吸引力最弱，而起始角色是玩家的投射对象，尤其冒险。
- **轴 5：** 烛火暖光主调——易滑向温馨。戏剧性硬光——大面积暗部在缩略尺寸下吃掉主体细节。
- **轴 6：** 纯功能色（色轮等距取五色）——浪费一层免费的世界观表达。
- **轴 7：** 拟物古物材质——小屏高密度下易脏、拉伸穿帮、状态变体费力。水墨笔触 UI——墨边的不规则轮廓与拉伸 / 最小触控尺寸相抵，灰态降饱和在墨色上读不出。
