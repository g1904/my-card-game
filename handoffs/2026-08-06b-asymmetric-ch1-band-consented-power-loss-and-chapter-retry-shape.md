**一行摘要：** 08-06 上午留下的三条 ⚠ 承重裁决项全部收口——**ch1 赋级带取非对称 `[−4, +2]`**（`lifeTotal` 冲突随之消失）、**法则不会被强制剥夺**（只有「玩家自愿的置换」能真正从账号移除，其余事件一律降级为**本轮回禁用**）、**`chapterRetry` = 角色级三个具名字段 + 通关后保留 + 账号级另有统计计数**；另答结两条形态项（降阶碾压**不**要独立呈现语言；赋级带分档**是内容配置**）。

## Intent（distilled）

### 一、ch1 赋级带取非对称 `[−4, +2]`，且分档写进内容配置

> **第一篇章的敌人赋级带 = `[角色全局等级 − 4, 角色全局等级 + 2]`；第二 · 第三篇章仍为 `±2`。** 三章的带边界**全部作为内容侧可调数值配置**，不是代码常量。

08-06 上午的对称 `±4` 是过渡形态：**放宽的动机全在下界**（`diff ≤ −3` 才够得着完整意图档），而**上界的 `+4` 才是把最坏落差抬到 17 的元凶**。取非对称即同时拿到两个目标，代价为零。

- **推论 ①（承重 · 一条 ⚠ 冲突就此消失）：「一次惨败不打穿耐久」在三章全部由规则层封住。** 上界维持 `+2` ⇒ ch1 最坏开局落差回到 **9**（炼气十三层 `baseMomentum` 15 遇筑基中期 24），在 `lifeTotal` 10/10 之内。**炼气 `lifeTotalLimit` 不必抬基线**，整条 `lifeTotal` 曲线与「一次惨败」的手感原样保留。
- **推论 ②：ch1 的落差区间只在领先侧被拉宽。** 精确量纲是**领先至多 6**（炼气十三层 15 遇炼气九层 9）、**落后至多 9**——上午记下的「`[−17, +17]`」这一粗略刻画随之作废。**第一篇章因此不是「等级差最富变化」的一章，而是「碾压侧更宽、被压侧不变」的一章**：新手期得到的是更多「打得动」的体验，而不是更多「被打穿」的体验，这与教学期的意图更贴合。
- **推论 ③：「越阶只出现在境界末段」恢复为三章统一的一句话——末两级。** 上午因 `+4` 而分裂出的「ch1 末四级 / ch2 · ch3 末两级」表述作废：`+2` 下 ch1 要到炼气十二 · 十三层才够得着筑基。**结构性推论回到最简形态**，不再需要分章各说一次。
- **推论 ④（新结构 · 值得留意）：ch1 的「完全无信息」档只由越阶硬门给出，同境界内不可达。** `diff` 上界 `+2` < ch1 的无信息门槛 `+3`，故炼气段内部永远给得出至少「仅类别」；黑箱**只在角色摸到炼气十二层之后**才出现。这不是缺口而是强化——**「开局看得清 → 收尾看不清」的信息曲线在 ch1 变得更干净、更陡**，黑箱成为「你已经站在突破前夜」的明确信号。
- **推论 ⑤：三档可达性核对（ch1，`diff ∈ [−4, +2]`）** —— `−4 ~ −3` 完整意图 ✓（碾压档可达，这正是放宽的目的）· `−2 ~ +2` 仅类别 ✓（常态档）· `≥ +3` 同境界内不可达，由越阶硬门补上 ✓。**三档在 ch1 全部有出口。**
- **推论 ⑥：带边界是内容配置 ⇒ 分档不再是结构性承诺。** 与意图阈值的三处门槛同级，`−4 / +2 / ±2` 全部随内容 overlay 可调；**「ch1 与 ch2 · ch3 不同」这件事本身也就退化为一份配置的取值差异**，代码侧只需读「当前篇章的带」这一个概念，不为分章写分支。这与既定的「平衡数值集中管理、系统从数据中读取」一致。

### 二、降阶碾压不需要独立的呈现语言

> **降阶碾压与「境界内 `diff` 拉开」的碾压共用同一套完整意图呈现**，UI 上不做区分，不加「不足为惧」一类的额外标注。

- **推论 ①：呈现层只认档位，不认档位的来源。** 完整意图 / 仅类别 / 无信息三档是呈现层的全部词汇；「这次为什么是完整意图」（降阶硬门 or `diff` 够低）是规则层的事，**不上浮到 UI**。这与「越阶黑箱不给任何替代线索」是同一种克制——两道硬门在呈现上都不自我声明。
- **推论 ②：玩家已有推断所需的全部输入。** 敌人等级在 eventOptions 上精确可见、自身等级已知，**境界归属可由等级直接读出**；再加一层标注是冗余信息，只会加重竖屏信息密度。
- **推论 ③：`IntentTier` 之外不需要第二个枚举。** 呈现层不必携带「碾压来源」字段，`CombatSnapshot` 的意图部分因此少一项。

### 三、法则不会被强制剥夺：置换（自愿）与本轮回禁用（其余）

> **事件侧移除 `Power` 时，玩家永远有选择权。** 真正从账号移除一条法则，**只能发生在玩家自愿接受的「置换」中**（例如「以此法则换取另一条法则」）；**其余所有事件的「失去法则」一律降级为「本轮回禁用」——法则不从账号删除，只在本次轮回内不生效。** 且这两类事件的**出现概率从内容侧限制**。

上午列的三个候选里，**③（真的永久剥夺）否决**；采纳的不是 ① 或 ② 中的任一个，而是**按「玩家是否点头」把通道一分为二**：

| 形态 | 触发方式 | 对账号的作用 | 适用对象 |
|---|---|---|---|
| **置换型剥夺** | **玩家主动选择**（有对价，例如换成另一条法则） | **真的移除**，写 PlayerProfile | 法则（PlayerPower）· 神通同理 |
| **本轮回禁用** | 事件 outcome / 负向条目，玩家未必同意 | **不删除**，仅本轮回不生效 | 法则（PlayerPower） |
| 战斗内 `IgnoresProtection` | 栈上结算的效果 | **不写 Profile**，仅本场 | 已入场的 `Power` 永久物 |

- **推论 ①（承重）：付费内容不会被游戏销毁。** 法则部分来自 premium bundle，**「花钱买到的东西可能被一个事件拿走」这条风险彻底关闭**——玩家点头才失去，且失去时拿到等价物。这与既定的付费边界（「花钱体验更好、不滑向 pay-to-win」）方向一致，且**免去了一整类客诉与退款争议**。
- **推论 ②：三级严重度阶梯就此成形。** 本场移除（战斗内）< 本轮回禁用（事件侧默认）< 账号移除（仅置换、需自愿）。**「失去法则」不再是一个二元事件，而是一条有梯度的压力线**，内容侧可按事件分量选择档位。
- **推论 ③：置换是一种正向设计，不是惩罚。** 「以一换一」本质是**卡组构筑式的取舍**（换掉不合本局流派的法则），而非纯粹的负向条目；它把原本会激起挫败的机制转成了一个有趣的决策点。**这条把「失去法则」从风险面挪到了设计面。**
- **推论 ④：「本轮回禁用」需要一个轮回级的抑制表达。** `status` 开关是**账号级**的持久字段（`PlayerPower.status`），不能拿它承载本轮回禁用——否则轮回结束后忘了恢复就等同于永久剥夺。**它必须落在轮回级状态上**（`CharacterProfile` 侧的一个被禁用 `Id` 集合），使轮回结束即自然失效。形态见 Open questions。
- **推论 ⑤：1% 的分子现在编排得出。** 分母已定（全部 AdventureEvent 九类），分子现在有了明确的构成——置换型事件 + 本轮回禁用型事件 + 战斗内带 `IgnoresProtection` 的遭遇，**三类合计约 1%**，且**概率控制归内容侧**（与既定的「稀缺性归内容侧纪律、代码只留 `PushWarning`」一致）。
- **推论 ⑥：`Power` 的「受保护」语义现在是三层，不是两层。** `IsProtected`（战场上的可针对性）· 本轮回持有的有效性（可被禁用）· 账号持有权（**只有自愿置换能动**）。上午说的「分层表述」在这里得到了具体的层数。

### 四、`chapterRetry` = 角色级三个具名字段 · 通关后保留 · 账号级另有统计计数

> **`CharacterProfile.chapterRetry` 是三个具名字段**（第一 / 第二 / 第三篇章各一），**不是字典或按索引的数组**；**重试成功通关后计数保留**，不清零。**`PlayerProfile` 上另有一份对应的账号级统计计数。**

- **推论 ①：⚠ ch1 计数的死字段问题由「两层各司其职」化解。** 角色级的 ch1 计数在现状语义下确实恒为 0（ch1 重试 = 随机生成新角色），但**它不需要有意义**——「你在炼气段重开了多少次」这个有意义的问题由**账号级统计计数**回答。**07-30b 的 ch1 重试语义因此不必改写**，上午列的候选 ②（改写 ch1 重试语义）不采用。
- **推论 ②：两层计数的口径不同，不是同一个数的两份拷贝。** 角色级 = **这个角色在该篇章用掉了几次重试**（与上限相减得「还剩几次」，是**闸门输入**）；账号级 = **这个账号在该篇章累计重开了多少次**（跨角色累加，是**统计 / 成就 / 元进程读数**，不参与任何闸门判定）。**只有角色级参与规则，账号级只被读来看。**
- **推论 ③：三个具名字段而非集合，与「篇章数固定为三」这条硬事实对齐。** 四境三篇章是游戏结构（见 `systems/game-progression.md`），不是可扩展的列表；具名字段让存档 schema 显式、读取处不必处理「键不存在」的分支，也免去按索引访问时的越界校验。**代价是新增篇章需要改 schema**——但篇章数不是设计变量。
- **推论 ④：通关后保留计数 ⇒ 它是历史，不只是配额。** 计数不随通关重置，故一个通关角色身上留着「我在筑基段挣扎了 3 次」的记录。**这给两处新可能**：元进程界面上的角色履历展示，以及成就 / 图鉴族之外的第四类账号积累读数（账号级统计计数）。**同时它简化了实现**——没有清零时机就没有「何时清零」的边界情形。
- **推论 ⑤：账号级统计计数是 `PlayerProfile` 上的一个新字段族。** 它与 `Achievements` 相邻但不同：成就是**有奖励的里程碑**，统计计数是**纯读数**。当前只有篇章重试这一项，但它天然是一个可扩展的统计位。

## 与既有决策的张力

1. **上午 handoff 的若干推论就此作废，须原地重写而非并列保留。** 具体三处：「ch1 越阶范围 = 末四级」（→ 恢复末两级）· 「ch1 落差区间 `[−17, +17]`」（→ 领先至多 6 / 落后至多 9）· 「ch1 是三章里等级差最富变化的一章」（→ 只在领先侧更宽）。**这不是推翻决策，是同一条决策收口后的数值更新**——按本库「只保留最新设计」的约定直接改写。
2. **「移除 `Power`」的 element 形态待答项被收窄，但未答结。** 语义已定（置换 / 禁用 / 不强制剥夺），但 `ProfileChangeSpec` 怎么表达这三类、置换的候选池从哪来、禁用集合落哪个字段仍未定——**问题从「要不要剥夺」下沉为「怎么写」**。
3. **「本轮回禁用」与既有的 `status` 开关模型语义相邻但必须分开。** `status`（账号级、玩家自己开关）与本轮回禁用（轮回级、事件施加）是两回事；实现上若混用同一个字段，会让轮回结束的恢复变成一次必须记得做的清理，**违背「轮回状态在轮回结束时被干净拆解」的既定纪律**。
4. **账号级统计计数是 `PlayerProfile` 上一个此前没有的字段族。** 既有的账号级字段清单（`List<CharacterProfile>` / `GameSetting` / `List<PlayerPower>` / `List<PlayerItem>` / `List<Achievements>` / 六个 Codex / `AccountInfo`）里没有「统计」这一类，需要补一项。

## Open questions

- **「本轮回禁用」的承载字段与生效面。** 落在 `CharacterProfile` 的哪个位置（一个被禁用 `PowerId` 集合？`Status` 内还是与 deck 平级？）；被禁用的法则在战斗中如何表现（**开局根本不入场**，还是入场后立刻被移除——前者更干净）；禁用是否对已在进行中的战斗立即生效；禁用状态是否对玩家可见（元进程界面上标注「本轮回失效」）。
- **置换型剥夺的候选池与对价规则。** 换来的法则从哪个池抽（全池？排除已有？同稀有度？）、玩家能否看到换来的是什么再决定、拒绝置换是否有代价（付出别的成本 / 事件无事发生）、以及**置换能否移除神通**（`Scope == Character` 的一侧尚未表态，虽然神通是轮回级、语义上无争议）。
- **`ProfileChangeSpec` 表达三类移除的 element 形态。** 按 `Id` 指定 / 随机 / 按 `Scope` 限定；「置换」是一个原子的双向 element 还是「移除 + 给予」两条；它能否出现在 `SelectCost` 侧（**置换作为选择成本似乎是合理的**，但禁用型不该出现在成本侧）；以及 08-04b 的 `PushWarning` 逐条列举是否要在事件 outcome 侧补一处对称落点。
- **账号级统计计数的字段形态与范围。** 落成什么（`PlayerStatistics` 类？直接挂 `PlayerProfile` 的三个字段？）；除篇章重试外首批还统计什么（总轮回数 / 总 defeated 数 / 各终结原因计数）；它是否参与云端同步的权威性判定（**统计计数被篡改无玩法后果**，或许可以走宽松口径）。
- **三章带边界作为内容配置的落点。** 与意图阈值的三处门槛放在同一份平衡资源里，还是分属各自的服务配置？是否需要加载时校验（例如「下界不得使 `diff` 门槛不可达」这类一致性检查）？
- **ch1 黑箱只在末两级出现，是否需要内容侧的额外编排。** 推论 ④ 指出炼气段前 11 级永远给得出至少「仅类别」——这是否让 ch1 前段缺少「读不懂对手」的紧张感，需要靠别的机制（探查的反面、剧本调制）补，还是**新手期本就不该有黑箱**（后者与教学意图一致，倾向不补）。
