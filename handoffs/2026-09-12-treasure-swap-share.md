## Intent（distilled）

法宝置换与法宝 / 古宝禁用已被判进「失去能力」上层 ≈ 1.0 的分子，**份额**留给 item 侧裁定。悬着的其实是同一件事的两半：份额是多少，以及它从哪里来——既有三支恰好占满 ≈ 1.0（神通 ≈0.5 · 法则置换 ≈0.3 · 法则禁用 ≈0.2），**分子里没有空位**；而供给护栏此前给法宝置换定的 ≈ 2 次 / 完整轮回，单独一项就是整份预算的 2 倍。

⇒ 「给一个份额」在算术上不是填空，而是**一次对上层分子的重新配平**。

### 1. 守住 ≈ 1.0，其余三支等比压缩 ×0.65

上层合计 ≈1.0 是被两个 ADR 明写的承重表述，**不动**；法宝一族的份额只能从既有三支里割，故三支**等比压缩**——等比 ⇒ 全序关系与神通内部 2 : 1 逐格自动保住，改的是一个数不是形状。

| 支 | 值 | 换算副本（分母 114） |
|---|---|---|
| 战斗内 `IgnoresProtection` | ≈1.11（不动 · 自持战斗分母） | —— |
| **轮回级能力损失** | **≈0.67** | ≈0.59% |
| ├ 神通置换 + 禁用（2 : 1） | ≈0.32（置换 .21 / 禁用 .11） | ≈0.28% |
| └ 法宝一族 | ≈0.35（置换 .28 / 法宝禁用 .06 / 古宝禁用 .01） | ≈0.31% |
| 法则置换型 | ≈0.20 | ≈0.18% |
| 法则禁用型 | ≈0.13 | ≈0.11% |
| **上层口径 = 持久支合计** | **≈1.0（不动）** | ≈0.88% |
| 四支合计（导出量） | ≈2.11（不动） | —— |

收敛核对：0.67 + 0.20 + 0.13 = **1.00**；四支合计 1.00 + 1.11 = **2.11**，与原值逐字不变（上层总额未动 ⇒ 导出量不动）。

**份额 0.35 的窗口两端各抵一条既有约束：** 低于 ≈0.28 时法宝置换压不过法则置换，「最轻的一端应最常见」只剩算术上的成立、内容侧读不出差别；高于 ≈0.35 时法则禁用被压得过薄。取上端，法宝置换 0.28 对神通置换 0.21 有 1.3× 的可辨识梯度。

### 2. 族内三分：置换 ≈0.28 · 法宝禁用 ≈0.06 · 古宝禁用 ≈0.01

- **置换 : 禁用 ≈ 4.7 : 1**（比神通侧的 2 : 1 更悬殊）：置换是**有同意的正向决策点**，而法宝在「持久度 × 是否经玩家同意」两轴上是最轻的一端——这条「最轻」几乎全部体现在置换那一格；禁用侧是无同意的施加，必须显著更稀有。
- **一处刻意的偏离：法宝禁用取 0.06 而非按两轴严格外推的 ≈0.13。** 严格外推它应比神通禁用更常见，但**法宝禁用的单次体感是全表最轻的**（储物袋里仍在、`Charges` 分毫不动、只是本轮回不可启动），撑不起一条 `Rare` 档事件的戏剧分量；且它与置换共享同一个 0.35 的池子，份额给禁用等于削掉那格真正兑现「最轻的一端应最常见」的置换。
- **法宝禁用 : 古宝禁用 ≈ 6 : 1**，兑现「禁用古宝的事件应比禁用法宝显著更稀有」。首批商店逐族库存深度记 `PlayerItem` = 0（不编排）⇒ 古宝禁用那 0.01 在首批内容上**实际为 0**，是给日后编排古宝预留的一格。

**全序核对：** 法宝置换 0.28 > 神通置换 0.21 > 法则置换 0.20 > 法则禁用 0.13 > 神通禁用 0.11 > 法宝禁用 0.06 > 古宝禁用 0.01。

### 3. 落位：并入既有的那一支，不新开第五行

「失去能力有四条支路」的枚举**不扩为五支**。四支表现有的行按**口径归属**切，而法宝一族与神通属同一类损失——禁用都是「不影响持有、轮回结束即恢复」，置换都是轮回级 build 损失且都写 Profile。故那一行改写为**「轮回级能力损失」**一支，内部分列神通与法宝一族：行数不变、枚举仍是四支。

### 4. 供给护栏 ③ 同批下调：≈ 2 → ≈ 0.28

那个 ≈ 2 是按法宝总供给 24 件的 8% **周转率**推出来的，而上层分子口径把它拉进一份总额 ≈ 1.0 的账——两条推导路径给同一个量两个相差 7 倍的值，必须有一个让位。取 ≈ 0.28，括号里的依据改写为「上层 ≈ 1.0 预算内法宝一族份额的置换那一格；折合法宝总供给 24 件的 ≈ 1.2%」。

**周转率视角的那个数不是没有位置，只是挂错了地方：** 法宝的日常周转由**随售与售出**承载——那两条是储物袋的常态弃置途径，不写「失去能力」这本账。

### 5. 已接受的代价

- **法则禁用 0.13 与神通禁用 0.11 落在「每 7~8 个轮回一次」的量级**，比「每 5 个轮回一次」更薄。上层总额是承重表述、不动，而各格本就自陈为待实测校准的初值；变的只是这一次失去能力由谁贡献——由最轻的法宝一族顶上，方向与两条轴同向。
- **玩家体感位移：** 法宝置换从「一个轮回撞上两次」变成「约每 3~4 个轮回撞上一次」。
